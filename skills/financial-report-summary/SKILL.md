# 财报结构化摘要

## 描述
将单篇财报正文提炼为结构化中文摘要，供投资者快速阅读。输出固定五个分区，
每区 3-5 条一句话要点。

## 触发条件
- 财报中心手动触发「生成摘要」（financial-reports/{id}/summarize）
- 服务层单轮结构化调用（run_structured），提示词契约见同目录 prompt.yaml

## 摘要分区
| 分区 | 内容 |
|------|------|
| 核心业绩 | 营收/净利润/扣非等总量结论与同比变化 |
| 营收与利润 | 收入结构、毛利率、费用与利润率变化 |
| 经营亮点 | 业务进展、订单、产能、市占率等正面信号 |
| 风险提示 | 财报明示的风险因素与负面变动 |
| 未来展望 | 经营计划、指引与资本开支方向 |

## 输入
服务层构造：标题 / 股票代码 / 报告类型 / 报告期 / 财报正文（可能截断）。

## 输出约束
- 严格基于财报正文，不得编造正文不存在的数据或结论
- 正文缺失某项信息时对应字段输出空字符串，不推测
- 数字保留原文口径与单位（亿元、%、倍等），同比/环比变化需注明
- 各分区使用 Markdown 无序列表（- 开头），每项一句，3-5 条
- 语言简洁专业，使用中文
