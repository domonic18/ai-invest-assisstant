# 市场热点检测

## 描述
基于资讯中心热点主题榜（`news-topic` 任务盘中 11:35 / 盘后 16:35 定时聚类近 24h
高分电报）做会话内即席分析：主题/情绪票数/热度构成/传导链为快照口径，
再交叉板块资金流与产业链信号给出可操作洞察。

## 触发条件
- 用户询问今天市场热点 / trending 主题或板块
- 用户询问市场情绪或资金异常
- 关键词：热点、热门、资金流向、情绪、异动、hotspot、trending

## 分析流程

### 步骤 1：读取当日主题快照
1. 查询 `news_topic_snapshot`（按 trade_date=今日、session 盘中/盘后，优先取最新）
2. 呈现主题卡：主题名、整体情绪（利好/利空/分歧）、票数分布、关联板块、传导链
3. 热度构成透明化：资讯量 × 板块涨幅 × 主力资金净流入（注意 `as_of_trade_date`
   标注：盘中快照的板块因子是 T-1 收盘口径，需向用户说明）

### 步骤 2：资金流交叉验证
1. 查询 `capital_fund_flow_sector` 最近交易日板块主力净流入
2. 将主题关联板块与资金流匹配
3. 标记「资金+情绪共振」（利好主题且大幅净流入）
4. 标记「背离」（利好主题但净流出，或利空主题但净流入）

### 步骤 3：产业链关联（可选深化）
- 对主题传导链中的环节，关联产业链图谱（`industry_chain_*` 表）识别代表公司
- 扫描突破信号关键词：突破/量产/首发/国产替代/扩产/投产/政策/补贴/新品

### 步骤 4：输出
对话内 Markdown 热点看板，按热度排序：
```json
{
  "topics": [
    {
      "title": "存储芯片涨价",
      "sentiment": "利好",
      "votes": {"bullish": 5, "bearish": 0, "neutral": 1},
      "sectors": ["半导体"],
      "heat": 70,
      "factors": {"news_count": 6, "sector_change_pct": 5.0, "fund_flow_net": 500000000},
      "chain": [{"event": "海外大厂减产", "link": "供给收缩", "stocks": ["688012"]}]
    }
  ],
  "divergence_alerts": [],
  "summary": "今日热点集中在…（资金/情绪共振提示）"
}
```

## 数据边界
- 主题/情绪/传导链以快照为唯一口径，不要自行重新聚类电报
- 快照未生成（节假日/任务未跑）时明确告知，退化为板块资金流排行 + 电报高频词描述
- 对未经证实的传闻标注「待确认」

## 备注
- 定时聚类由 `news-topic` collector 任务承担（本 skill 不重复生成快照）
- 交叉验证交易所官方公告，资金流数据注意口径交易日
