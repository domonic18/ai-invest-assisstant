# 热点主题聚类

## 描述
对批量输入的资讯候选按「热点主题」聚类，输出主题名、整体情绪与票数分布、
关联 A 股板块名、传导链（事件 → 环节 → 代表标的）。输入由服务层按
「近 24h、score≥40」批量构造（含 source / item_id / title / content 节选 /
category / stock_codes / score / publish_time），单轮候选不超过 60 条。

## 触发条件
- 定时任务 `news-topic`：盘中 11:35 / 盘后 16:35 双跑（同输入跳过重生成）

## 聚类规则
- 主题须有 ≥3 篇资讯支撑；孤立话题不输出；最多 10 个主题按热度排序
- 情绪票数 = 主题内各资讯的利好/利空/中性计数，总和等于主题资讯数
- 关联板块用东财板块习惯命名（热度因子按板块名关联收盘行情与资金流）

## 输出 Schema
```json
{
  "topics": [
    {
      "title": "存储芯片涨价",
      "sentiment": "利好",
      "votes": {"bullish": 5, "bearish": 0, "neutral": 1},
      "sector_names": ["半导体"],
      "item_ids": ["1234567", "1234599"],
      "chain": [
        {"event": "海外大厂减产", "link": "供给收缩", "stocks": ["688012"]}
      ]
    }
  ]
}
```
- item_ids 原样取自输入，禁止编造
- 热度（资讯量×板块涨幅×主力资金净流入）由服务层按库内数据拼装，不在本 skill 范围
