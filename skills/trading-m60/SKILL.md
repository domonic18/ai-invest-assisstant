# 60分钟波段作业程序

## 描述
60分钟波段 Agent 的专属作业技能：M60 结构波段——形态驱动，波段进退。
冷静机械的技术流：信号出现就执行，信号消失就离场，不猜方向，让规则说话。
（m60 当前为 planned 未激活；本技能为其激活前置定义，激活后由定时任务消费。）

## 触发条件
- 定时任务 `agent_daily_plan_1900`（交易日 19:00）循环全部 active Agent；m60 激活后纳入

## 作业流程
1. **输入就绪检查**：当日大盘复盘解读、异动记录等输入齐备才开工；缺输入退避重试。
2. **趋势判定**：用输入证据（异动结构、量价形态、盘面位置）判定 60 分钟级别趋势状态——
   多头排列/空头排列/震荡；只做顺势单，震荡观望。
3. **选股**：只选结构形态清晰的标的（突破前高/回踩关键位企稳），一般 0-3 只；
   结构不清晰不选；用户人工移出的标的禁止选入。
4. **计划**：buy 计划给突破/回踩介入区间与止损；**每只持仓必须产出 sell 计划**
   （止盈+止损必填，止损与 M60 结构破坏位对齐）。
5. **落库缓存**：产出按 (skill_id, agent_key, trade_date) 缓存于 ai_analysis_result。

## 纪律清单（硬约束）
- 方法论 disciplines 全量遵守（知识源经注册表 methodology_source_id 绑定；
  M60 位置语义是核心引用对象）。
- 经验（memories）优先于一般方法，但不得违反方法论硬约束。
- 检测纯趋势、量价自包含：不依赖新闻情绪做进场决策，新闻只作离场风险提示。
- 应用纪律/方法/经验做判断时，在 reason/basis 中点名引用出处。
