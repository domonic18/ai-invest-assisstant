## 2. 未完成项

### 2.1 批次 8b：影子期 → active 决策

- **现状**：`trading_agent.intraday_exec_mode='shadow'` 全链路判断但不下单，2026-09-29 起运行；
  observation 表逐 tick 留痕，供校准与复盘使用。
- **决策证据**：L0 触发区间命中率与误触发分布、L1 置信校准曲线（判断概率 vs 事后走势）、
  抑制原因分布、openjev 对照臂同题面 A/B 结果。
- **切换动作**：admin 将 `intraday_exec_mode` 置 `active`；置信门控阈值按影子期校准数据
  定版，并按 `model_version` 键控（不同厂商 confidence 口径不可移植）。
- **门槛**：影子期样本足以让校准曲线收敛（原定 1–2 周，以数据收敛为准），且对照臂结论
  无阻断性问题。

### 2.2 批次 9 收尾：对话记忆工具

- **已交付**：`agent_memory` 表与服务（幂等沉淀 + 编辑/停用/手动沉淀）、复盘 experiences
  同事务自动沉淀、`agent-daily-plan` 输入注入 active 记忆、admin 端点与「Agent 记忆」
  前端面板。
- **剩余**：对话路径的记忆工具（Agent 在会话中查询/新增/停用记忆），需注册进
  `build_trading_tools()` 并递增 `TOOLS_VERSION`。
- **闭环验证**：沉淀一条「追高风险」纪律记忆 → 次日选股/计划 prompt 引用（日志验证）；
  停用后次日不再引用。

## 4. 决策记录（已全部拍板）

| # | 决策 | 结论 |
|---|---|---|
| D1 | 盘后同步时刻 | **16:00**（清算稳定 + 退避窗口足） |
| D2 | 模拟交易页入口形态 | **独立页 `/paper-trade`**，菜单名「模拟交易」 |
| D3 | 复盘产出粒度 | **日度为主 + 周度/月度汇总**——同一任务内日历判定加发，不单独建 cron |
| D4 | 复盘落库 | **复用 ai_analysis_result**（skill_id 区分） |
| D5 | 下单确认阈值 | **±3%，仅提示不阻断** |
| D6 | 定时执行确认模式 | **全自主 + 事后通知**——计划生成即生效，不设人工审批；执行动态页可见（arch/10 §7），人工干预 = 移出自选 / 取消计划 |
| D7 | Agent 分组形态 | **现有自选页内 Agent 分组**（`owner_type='agent'`），AI 徽标 + 依据可见，可移出不可加入 |
| D8 | 记忆沉淀语义 | **落 Agent 自有记忆（`agent_memory`），不经 KB 审核流**：自动提取直接 active + 手动沉淀 active（source 标记区分）；人工干预 = 查看 / 停用 |
| D9 | 盘中触发方式 | **5 分钟条件轮询 + 14:50 尾盘强检**——已被 D21 修订：轮询升级为盘中常驻快反应服务，尾盘强检语义保留 |
| D10 | 执行自主度风控 | 服务层硬校验参数化：单票 ≤20% / 总仓 ≤80% / 单日 ≤10 笔 / 禁 ST / T+1 |
| D11 | 盘中判定引入 Jev | 2026-09-24 暂缓留缝（数值比较超出能力边界）；**2026-09-28 反转为采用**，任务重框为执行概率判断（D21），数值比较与风控仍归确定性代码 |
| D12 | 柜台凭证配置 | **入库配置，env 退役**——`paper_trade_account` 表（token Fernet 加密）；sidecar 无状态化，凭证每请求头传递；`PAPER_TRADE_URL` 保留 env |
| D13 | 多租户账户 | **每用户自有账户自配**（未配置展示引导）；多账户选择器；counter account 全局唯一；每用户上限 10 个；有本地数据的账户只可停用不可删 |
| D14 | 人机账户关系 | **人机分账户**——Agent 账户后台指定且全局唯一（部分唯一索引兜底），人工下单/撤单对其 403；委托表 `order_source` 留归因过滤基础 |
| D15 | 人工交易入口 | **下单卡 + 未完结委托撤单**（限价/市价 × 买/卖），仅限自有非 Agent 账户；不做改单（撤单重下替代） |
| D16 | 交易 Agent 定位 | **系统级单例独立 Agent（不多租户）**——模拟一名交易员；与侧边栏助手及复盘域解耦：只读其产出、不回写，产物落自有域 |
| D17 | 前端承载与权限 | **独立页 `/trading-agent`（admin-only）**：对话 + 计划 + 执行动态 + 复盘 + 记忆 + 配置；对非 admin 的唯一可见面 = 自选页 Agent 分组 |
| D18 | 工具归属 | **交易写工具从侧边栏助手剥离，交易 Agent 专属**；对话路径（ask_user 确认）与定时路径（全自主）共用服务层下单出口 |
| D19 | 配置面 | **`trading_agent` 注册表为真相源**：模型绑定 + 风控参数 + 自主执行总闸；不走 env；定时任务启停复用采集管理既有开关 |
| D20 | 批次优先级 | **人工交易体验先行**（2026-09-24）——Agent 闭环顺延为批次 5–9；人工体验对标同花顺核心路径，不做五档盘口与人工条件单 |
| D21 | 批次 8 执行架构 | **慢思考 + 快反应双模型**——慢思考 = Celery 定时链（盘前计划 / 盘中校准 / 盘后复盘）；快反应 = 常驻服务四层栈（L0 确定性 → L1 判断模型 → L2 升级 → L3 人工）；柜台条件单出局；Jev 由暂缓反转为快判断层（三条硬约束：版本 pin / 分档置信门控 / 判断全留痕）；8a 影子 → 8b active |
| D22 | 盘中慢快交互 | **早盘/午盘各一次计划校准**（10:20 / 13:20）——快反应供盘中观察报告，慢模型出结构化计划修正单（maintain/adjust/cancel/add），过 L0 硬校验后落新版本；校准动作在复盘 verdict 中可归因 |
| D23 | 判断模型封装 | **接口契约 vendor 无关**——押注接口（state + 类型化问题 → 概率答案 + confidence）不押注厂商：内部契约 `app/core/decision_model`，adapter 隔离厂商；配置走 `llm_config` purpose=`decision`；双路失败降级纯 L0，禁止用阈值近似替代判断 |
| D24 | 影子期对照臂与备链 | **影子模式加 openjev 对照臂**（同 wire API、同 state 同题面、只换 base_url 的严格 A/B）；备链顺序 = 主 OpenRouter/Jev → 备 openjev/Codiv → TypeSafe 直连押后；门控阈值是 per-vendor 资产，按 `model_version` 键控；本期不自托管 |
