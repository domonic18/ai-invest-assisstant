# 智能中枢「虚拟办公室」拟人化改版设计需求

状态：需求定稿待评审（2026-09-30）· 原型：`docs/prototypes/agent-hub-office.html`（图 1 主布局）· `docs/prototypes/agent-hub-office-mapping.html`（图 2 映射总览）
涉及页面：`web/src/pages/AgentOverview/`（智能中枢）

## 1. 背景与问题

| # | 问题 | 现状 |
|---|------|------|
| P1 | 「agent 在干什么」不可读 | `AgentHubStage` 的 Agent 单元只有状态点 + 文字徽章（作业中/待命），与下方资源站图例无视觉关联——看不出是在查知识库、看大盘、制定计划还是复盘 |
| P2 | 实时决策流不可读 | `LiveDecisionFeed` 置于页面底部，每条 `ObservationRow` 是宽行文本，容器窄导致滚动感知差，与「控制台日志」的预期相去甚远 |

## 2. 设计目标

1. **拟人化**：Agent 是办公室里的「小人」，用场景动作（睡觉/打盹/敲电脑/盯盘/写字/翻书）表达运行状态，替代文字徽章为主的呈现。
2. **空间叙事**：左侧大画布是办公室，右侧窄栏是决策流；agent 在哪里、对着什么资源，就是在做什么。
3. **延时可接受**：动画不追求逐 tick 实时（函数调用秒级完成），允许状态驻留与走位过渡（见 §6）。
4. **多 Agent 共存**：虚拟办公室同时呈现全部注册 Agent；长线 Agent 长期呈现休息态。

## 3. 左侧画布：办公室场景

### 3.1 资源映射（发散自现有五站 + 业务域）

| 场景元素 | 对应业务 | 现有站点 |
|----------|----------|----------|
| 行情大屏（墙上，红绿 K 线） | 大盘/指数行情 | quote 域 |
| 交易终端（多屏、下单热线） | 盘中执行/模拟盘下单 | paper 站 |
| 计划工位（单屏电脑+便签板） | 制定/校准交易计划 | plan-input 边 |
| 复盘书桌（台灯+笔记本） | 复盘/归因写作 | review 站 |
| 知识库书架（书脊+检索光） | 方法论基座检索 | kb 站 |
| 资讯电视（滚动电报条） | 电报/公告 | news 站 |
| 抖音电视（短视频流+情绪气泡） | 大V情绪 | sentiment 站 |
| 休息区沙发+绿植 | 未启用/长期休息 | — |
| 墙上时钟 | 北京交易时段（09:30-15:00） | marketSession |

### 3.2 Agent 状态机 → 场景动作（关键：打盹 ≠ 休息）

| 状态（runtimeState 细化） | 场景动作 | 视觉 |
|---------------------------|----------|------|
| 未启用（off/planned） | **休息**：躺在休息区沙发 | 灰调 + 「未启用」牌 |
| 启用待命（idle） | **打盹**：伏在计划工位小睡 | 彩色但 Zzz 气泡，工位有属于他的名字牌 |
| 制定计划/校准（planning，19:30 生成、10:20/13:20 校准窗口） | 坐计划工位敲键盘；校准时在便签板贴条 | 键盘敲击动效 |
| 盯盘执行（trading，盘中 working） | 坐交易终端前盯盘，偶尔抬手下单 | 屏幕红绿反光、下单热线亮 |
| 复盘学习（reviewing，盘后） | 坐复盘书桌写字/翻书 | 台灯光晕、笔记翻页 |
| 查阅知识库（researching） | 站书架前翻书 | 书架检索光带 |
| 看资讯/刷抖音（scanning） | 站资讯电视/抖音电视前 | 电视高亮、agent 背光 |

> 打盹（启用但在控件中）与休息（未启用）必须可区分：前者坐在**自己的工位**、保留 accent 色与名牌；后者在公共休息区、整体灰调。

### 3.3 视觉基调（科技风指挥中心 + 机器人小队）

- **画布 = 深色科技指挥中心平面图**：整体保持深色底；地板发光网格 + 雷达圈，墙体双线霓虹描边，气闸式入口；资源科技化改名——全息行情大屏 / 资讯数据流屏 / 情绪流媒体屏（抖音）/ 知识晶体库（kb）/ 计划终端工位 / 交易操作台（+红色紧急通讯器）/ 复盘分析台（扫描光圈）/ **充电休眠舱**（替代休息区沙发）/ 数据服务器柜 / 能量光柱。
- **小人 = 圆胖 Q 版机器人**（体型语言继承 Marvis 的可爱比例）：深色金属壳 + 面部黑色视窗屏 + **发光 LED 眼**；**能量环色 = Agent 身份色**（颈环/胸口核心/天线呼吸灯同色：青=短线猎手、紫=M60、灰=长线未启用）。选中态用四角锁定框（targeting reticle）。
- **状态光语义**：工作中=眼睛亮 + 天线呼吸灯全亮；待机（启用但空闲）=眯眼短横 + 微亮，坐自己工位；休眠（未启用）=视窗熄灭 + 接充电线，躺公共充电舱 +「未启用 · 休眠」牌。
- 气泡用深底 + 身份色描边圆角胶囊；`prefers-reduced-motion` 时光效降级为静态。

## 4. 右侧栏：拟人化实时决策流

- **位置**：左右分栏，左侧画布 `flex-1`，右侧固定宽 ~380px 全高。
- **叙事化**：每条观测由「原始行」改为「一句人话 + 附属数据」，由前端文案模板映射（`ObservationRow` 字段 → 句式），示例：
  - 无动作心跳 → 「盯着浦发银行的分时看了 3 个 tick，按兵不动」
  - 执行 → 「10.98 元把买单递给了柜台」（附：`buy 600000 · paper`）
  - 抑制 → 「想追高，忍住了——价格已超买区上沿 30%」
  - 校准 → 「午间校准：把止损 9.5 上移到 9.8，贴了张便签」
  - 方法论 → 「翻开《趋势理论》，翻到买点确认那章」
- **Agent 过滤**：点击左侧小人 → 右栏切换为他的决策流（沿用 selectedKey）；未选中回退首个 active。
- **滚动感**：窄卡片（句子 + 弱化 mono 附注），新行滑入 + 自动贴底；心跳类弱化行折叠密度，显著事件卡片高亮——保留「控制台在滚」的体感，但内容可读。

## 5. 动效与延时策略（需求 3）

1. **状态最短驻留**：场景动作变更设最小保持窗（建议 8-10s），窗口内的状态抖动合并（只记最新）。
2. **走位过渡**：状态对应地点变化时，小人以 3-5s 步行动画走到新地点，不瞬移；过渡期头顶气泡显示「走向 xx」。
3. **动画节拍与业务解耦**：动画帧率/节奏固定，不随 tick 频率抖动；决策流保持 15s 盘中快轮询（已有）。
4. `prefers-reduced-motion` 全部降级为静态姿态（沿用现有约定）。

## 6. 数据契约（现状 vs 缺口）

| 能力 | 现状 | 缺口 |
|------|------|------|
| Agent 运行态 | `runtimeState`（off/idle/working/done） | 需细化为 §3.2 的 7 态（建议后端 overview 接口派生 `activity` 字段：由最近 collector_log 任务域 + 盘中观测 + 校准窗口推导） |
| 决策流内容 | live observations（tick 级 action/suppression/verdict） | 无缺口，纯前端叙事化映射 |
| 资源联动高亮 | 无 | 纯前端：activity → 场景元素点亮 |
| 多 Agent 同屏 | overview 列表已有 | 无缺口 |

## 7. 分期实施

- **一期（纯前端，无后端改动）**：左右分栏重排；办公室场景 + agent 静态姿态（SVG 分层，位置由现有 runtimeState 粗映射）；决策流叙事化文案 + 右栏化。
- **二期**：走位动画 + 状态驻留队列；后端 `activity` 细化字段接入；资源联动点亮（边缘流光）。
- **明确不做**：3D/骨骼动画；逐 tick 精确同步；语音/音效。
