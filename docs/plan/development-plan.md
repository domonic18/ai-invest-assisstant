## 2. 待开发（V1.3，单人节奏约 2 周/迭代）

| 迭代 | 主题 | 内容概要 | 依赖 / 风险 |
|------|------|----------|--------------|
| 迭代 1 | 信息架构与设置域 | 侧边栏四分组重组；研报 / 财报并入个股右栏 tab，`/research`、`/financial-reports`、`/hotspot` 下线；技能广场前端页（广场浏览 / 安装 / 自定义技能 CRUD，对齐 `skill-square.html`）；设置页增强（邮箱编辑 + 修改密码，对齐 `settings.html`） | 纯前端为主，后端 API 已就绪；个股页手动触发采集的权限边界为唯一决策点 |
| 迭代 2 | 监测分组数据扩展 | 二批全球指标（港美股指数 / 日债 10Y / 加息概率）调研与接入——加息概率走 CME FedWatch 逆向属高风险，调研不过降级为 FOMC 日历占位；板块行情采集（行业 / 概念）；`/macro-monitor` 新页；`/capital-flow` 板块监测升级 | 数据源调研先行，失败按预案降级，不做伪数据 |
| 迭代 3 | 资讯中心基础 | 渠道监控条；电报 AI 重要度分级（ai_score 另存，不覆盖源数据）；`/news` 三视图骨架上线（电报视图自 `/telegraph` 迁入） | 依赖迭代 1 导航 |
| 迭代 4 | 资讯中心 AI 增强 | 重点与事件故事线（AI 评分 + 同主题聚类 + 手动跟踪）；我的订阅（关键词命中回流电报流）；热点主题榜（F-AI-03：主题 / 情绪 / 热度构成 / 传导链） | 聚类口径与 token 成本 |
| 迭代 5 | 异动分析闭环 | 板块 / 个股异动检测算子（盘后规则任务）；top-N AI 归因（侧边栏手动重分析）；`/anomaly` 双页上线 → **V1.3 全量发布** | 依赖迭代 2 板块行情、迭代 3 资讯查询能力 |

**V1.3 发布门槛**：迭代 1-5 完成；验收基线全绿（backend pytest / mypy / ruff，web typecheck / lint / test / build）；新页对照原型走查；旧路由下线无死链。
