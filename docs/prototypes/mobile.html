移动端适配原型

断点 ≤768px 启用移动布局 · 解决手机端访问时每日复盘等核心功能不可用的问题

导航模式

  • 侧边栏 → 汉堡按钮 + 左侧抽屉导航
  • 核心功能 → 底部 Tab Bar（复盘/竞价/资金/我的）
  • 页面标题收进 App Bar，不重复占位

内容重排

  • 多列网格 → 单列纵向堆叠
  • 数据表格 → 卡片式列表（关键字段前置）
  • 统计卡片一行 3 个，数值优先、标签精简

图谱与弹层

  • 产业链图谱：双指缩放 + 拖动，默认 fitView 全图
  • AI 助手 Drawer → 全屏底部弹层（78% 高，可下滑关闭）
  • 版本对比/详情 → 全屏页面而非侧拉抽屉

触控规范

  • 触控目标 ≥ 36×36px（按钮/Tab/列表项）
  • 正文字号 ≥ 12px，数字用等宽字体
  • 涨跌配色遵循国内习惯：红涨绿跌
