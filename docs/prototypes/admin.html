实现说明（本页与 web/ 实际代码一一对应）
① 主页 /admin：Admin.tsx — ADMIN_LINKS 八个入口卡片（四列栅格：用户管理 / 股票管理 / 报告管理 / 资讯管理 / LLM 配置 / MCP 服务 / 分析结果 / 采集管理）+ 最近采集日志（前 10 条，「查看更多」跳采集管理）；代理配置不占主页卡片，经侧边栏「后台管理」子菜单进入。
② 子页均为独立路由，原型纵向排列示意；旧 /admin/tasks、/admin/collector-channels 已 301 重定向至采集管理对应 Tab。
③ 报告管理：顶部存储统计卡片来自 GET /admin/reports/storage-summary（file_metadata 按 file_type 聚合 MinIO invest-files 的文件数与字节数）；「清理 3 个月前报告」经 modal.confirm 二次确认后删除报告 PDF 及存储对象；下方研报 / 财报双 Tab（列表筛选与下载 / 删除）。
④ MCP 服务：McpServers.tsx — CRUD + 行内连接测试（成功弹工具清单，失败给可读错误）；表单支持从 Claude Desktop / Cursor 标准 mcpServers JSON 导入预填，HTTP(SSE) 与 stdio 双形态表单；启用后工具经 langchain-mcp-adapters 注入 AI 助手，保存 / 修改配置即自动重建 agent。
⑤ 分析结果：顶部 Tabs 由后端 skill 注册表驱动（新增 skill 自动出现）；「AI 重新生成」经侧边栏助手 sendQuestion 触发，生成完成事件刷新列表；删除为缓存清除语义（清空该业务键全部历史）。
⑥ 采集管理三合一 Tabs（与 ?tab= 同步）：执行与日志（任务目录按钮来自后端 TASK_SPECS，点击弹渠道选择 + 高级选项，下方最近 20 条日志七列）；任务配置（cron 中文释义，悬停显原始表达式，触发 / 暂停·恢复 / 编辑 / 删除）；渠道配置（内层再分渠道 × 支持数据类型、数据类型优先级降级链两视图）。
