实现说明（本页与 web/ 实际代码一一对应）
① 主页 /admin：Admin.tsx — ADMIN_LINKS 十个入口卡片（四列栅格，图标色对齐 tailwind blue/green/purple/orange/cyan/pink/teal/amber/gray/indigo）+ 最近采集日志（前 10 条，「查看更多」跳采集任务页）。
② 子页均为独立路由，原型纵向排列示意；侧边栏无二级导航，返回靠浏览器回退或重新进入后台管理。
③ 任务管理：执行时间显示 cron 的中文释义（悬停显示原始表达式）；操作含触发 / 暂停·恢复 / 编辑 / 删除。
④ AI 结果管理：顶部 Tabs 由后端 skill 注册表驱动（新增 skill 自动出现）；「AI 重新生成」经侧边栏助手 sendQuestion 触发，生成完成事件刷新列表；删除为缓存清除语义（清空该业务键全部历史）。
⑤ 跟踪指数：最新值 = 收盘价 + 涨跌幅（红涨绿跌，scheme-aware）；启用列 Switch 即时生效；此清单同时驱动工作台 / 复盘页的市场快览。
⑥ 采集渠道：双 Tab。渠道配置声明「渠道 × 支持数据类型」；数据类型优先级配置失败自动切换的降级链（↑↓ 调序、✕ 移除、按类型保存）。
⑦ 采集任务：任务按钮来自后端任务目录（点击弹渠道选择 + 高级选项弹窗），下方为最近 20 条执行日志（七列，含结束时间与错误信息）。
