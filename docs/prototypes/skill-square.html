龙头战法每日复盘
@zhangwei · v2 · 安装于 2026-09-05
注入助手
内置技能 随平台版本更新，始终对 AI 助手可用
◆ 大盘每日复盘 · 涨停复盘归因 · 个股每日分析 · 产业链分析 · 自选股截图识别 · 研报摘要 · 财报摘要 · 热点检测 · 产业链突破挖掘 · 财务健康检查（10 项，详见技能广场）
实现说明（对齐批次 7 已交付的后端 API）
① 端点映射：广场列表 = GET /api/v1/skills（返回 available + mine 两组）；安装 = POST /skills/{id}/install（201；重复安装 409）；卸载 = DELETE /skills/{id}/install（204）；创建 = POST /skills（skillId 撞内置保留字或他人技能 409）；编辑 = PATCH /skills/{id}（仅本人，version 自增）；发布 = POST /skills/{id}/publish（仅本人）。
② 内置技能语义：10 个 builtin 随镜像分发、目录全量挂载给助手（开箱即用，无需安装）；「安装 / 启用开关」的注入语义主要作用于自定义技能——安装且 enabled 的 custom skill 以索引行（技能名：描述）注入助手上下文，全文按需读取（渐进披露）。
③ kind 四类：可执行（有执行器，定时 / 页面双路径）/ 提示词（助手按需调用）/ 方法论（知识文档）/ 自定义（用户配置，DB JSONB）。
④ 自定义技能 = 配置非代码：无执行沙箱，不支持联网取数工具以外的能力声明；allowed_tools 约束本批不执法。
⑤ wire 契约：shared/types/skill.ts 已有（ApiSkillItem 等 camelCase），前端页面 / hooks 待批次 J 落地。
创建自定义技能
小写字母 / 数字 / 连字符；全局唯一，不可与内置保留字冲突（冲突返回 409）。创建后不可修改。
将作为索引行注入 AI 助手上下文（一行摘要，写清楚"什么时候用这个技能"）。
frontmatter 的 name / description 会同步为技能元信息；正文是助手执行时读取的方法论。
支持 {"{placeholder}"} 占位符，调用时替换；留空则直接透传用户问题。
