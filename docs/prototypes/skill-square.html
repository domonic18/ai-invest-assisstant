大盘每日复盘

描述

以工具实时取数为依据，为整个 A 股市场生成当日收盘复盘：大盘综述、技术面分析、资金面分析、情绪与连板分析、风险提示与策略建议五个分区。分析流程与工具编排由本文件维护，输出分区契约以 prompt.yaml 为准。

触发条件

  • 每日复盘页请求生成 AI 大盘综述
  • 每日收盘后的定时任务（market_daily_review_1630，北京时间 16:30）

输出 Schema

{
  "sections": {
    "overview": "AI 大盘综述（Markdown）",
    "technical_analysis": "技术面分析（Markdown）",
    "capital_analysis": "资金面分析（Markdown）",
    "emotion_analysis": "情绪与连板分析（Markdown）",
    "risk_advice": "风险提示与策略建议（Markdown）"
  }
}

可用工具

执行器路径固定注入前四个取数工具；后三个仅助手对话路径可用。

  • get_market_overview(trade_date)：四大指数行情 + 全市场统计——两市成交额（含环比）、上涨/下跌/平盘家数、涨停/跌停家数、情绪温度、涨停比、连板率、炸板率
  • get_index_technical(trade_date)：五标的（沪指/创业板/科创50/沪深300ETF/富时A50）预计算技术面文本，必须直接引用，禁止自行估算
  • get_sector_overview(trade_date)：行业板块概览——涨跌幅热力图、主力净流入/净流出 TOP5、领涨板块
  • persist_market_review(trade_date, sections)：仅助手对话路径——将五分区复盘保存入库，复盘页卡片自动刷新

分析流程

步骤 0：交易日确认

助手对话路径先调用 get_trade_calendar 获取最近交易日；独立执行器路径直接使用任务指令给定的 trade_date。数据缺失自愈：任一取数步骤返回空数据时，调用 collect_market_data 派发补采任务（涨停池/成交额约 1 分钟、板块资金流约 10 分钟），重试后仍缺失时如实披露，不得编造。

步骤 1-4：大盘概览 → 技术面 → 连板情绪 → 资金面

依次调用四个取数工具，为对应分区准备数据；金额必须带正负号（净流入为正、净流出为负）。

步骤 5：撰写分区并交付

助手对话路径调用 persist_market_review 保存；独立执行器路径按「输出 Schema」输出 JSON。

规则

  • 所有数据必须来自工具调用结果，不得编造；工具未覆盖的维度如实说明
  • 简体中文 + Markdown；每分区 3-5 个要点、每点一行
  • 涨跌幅与资金金额必须带正负号（前端据此自动着色）
  • 客观提示风险，不给出确定性涨跌预测，不构成投资建议
