## 2. 各数据源详细分析

### 2.1 巨潮资讯 (cninfo.com.cn) — 核心数据源

巨潮资讯是证监会指定的上市公司信息披露网站，数据最权威、最全面。

| 数据类型 | 接口/页面 | 采集方式 | 更新频率 | 备注 |
|----------|----------|----------|----------|------|
| **公司基本信息** | `/new/singleLogin/singleLogin` | API 接口 | 每日 | 股票代码、公司全称、行业分类、注册资本 |
| **定期报告** | `/new/disclosure` | 列表页+详情 | 每季/每半年/每年 | 年报、半年报、季报 |
| **临时公告** | `/new/disclosure` | 列表搜索 | 实时 | 重大事项公告、重组公告等 |
| **财务报表(PDF)** | `/new/fulltextSearch` | PDF 下载 | 随披露更新 | 资产负债表、利润表、现金流量表 |
| **公司治理** | `/new/commonUrl` | 页面爬取 | 每日 | 股东信息、高管信息 |
| **IPO 信息** | `/new/ipoInfo` | 页面爬取 | 每日 | 招股说明书、发行公告 |

**关键技术难点**：
- 登录态管理：cninfo 需要登录才能查看部分内容，需维护 Cookie/Session
- 验证码：某些高频操作可能触发验证码，需集成打码服务或 IP 代理池
- PDF 解析：财报 PDF 多为扫描版，需 OCR 或利用文本层提取结构化数据

**采集策略**：

```
调度频率：
  - 定期报告：每季度财报披露季（1月-4月、7月-8月、10月）每日扫描
  - 临时公告：每小时增量采集
  - 公司信息：每日全量刷新

反爬策略：
  - IP 代理池（付费代理服务）
  - 随机 User-Agent
  - 请求间隔随机化（3-10 秒）
  - Cookie 池维护（多账号轮换）
```

### 2.2 同花顺 (10jqka.com.cn) — 交易数据核心

| 数据类型 | 接口/页面 | 采集方式 | 更新频率 | 备注 |
|----------|----------|----------|----------|------|
| **K 线数据** | akshare 封装接口 | API | 每日盘后 | 日K/周K/月K/分钟K |
| **集合竞价** | 实时接口 | WebSocket/轮询 | 盘前 9:15-9:25 | 量价变化 |
| **分时数据** | 实时接口 | WebSocket | 盘中实时 | 分时成交 |
| **研报中心** | `/stock/report` | 页面+API | 每日 | 券商研报列表 |
| **资金流向** | akshare 接口 | API | 每日 | 主力/游资/散户资金流 |
| **行业板块** | `/plate` | API | 每日 | 板块涨跌/资金流入流出 |
| **龙虎榜** | akshare 接口 | API | 每日盘后 | 上榜营业部、买卖金额 |

**接口示例（通过 akshare）**：

```python
import akshare as ak

# K线数据
stock_zh_a_hist_df = ak.stock_zh_a_hist(
    symbol="000001", period="daily",
    start_date="20240101", end_date="20240701", adjust="qfq"
)

# 资金流向
money_flow_df = ak.stock_individual_fund_flow(
    stock="000001", market="sh"
)

# 龙虎榜
lhb_df = ak.stock_sina_lhb_detail_daily(
    date="20240701"
)
```

### 2.3 东方财富 (eastmoney.com) — 数据补全

| 数据类型 | 接口/页面 | 采集方式 | 更新频率 | 备注 |
|----------|----------|----------|----------|------|
| **财务报表** | `/api` 数据接口 | HTTP API | 随披露更新 | 结构化 JSON 返回 |
| **板块资金流** | `/api` 板块接口 | HTTP API | 每日 | 行业/概念板块 |
| **基金持仓** | 基金持仓接口 | HTTP API | 每季 | 十大重仓股 |
| **研报** | 研报中心 API | HTTP API | 每日 | 可获取 PDF 下载链接 |

**东方财富的核心优势**：提供相对稳定的 JSON API，数据结构化程度高，是 akshare 主要的数据来源之一。

### 2.4 新浪财经 — 新闻与实时行情

| 数据类型 | 接口 | 更新频率 | 备注 |
|----------|------|----------|------|
| **个股新闻** | 新闻 API | 实时 | 利好/利空新闻聚合 |
| **实时行情** | 行情接口 | 盘中实时 | 可作为同花顺的备选 |
| **宏观经济** | 数据接口 | 每日 | CPI/PMI/GDP 等 |

## 3. 数据源优先级与故障切换

```
优先级1 (核心):  巨潮资讯 → 财报PDF/公告/公司信息
优先级2 (核心):  同花顺 → K线/集合竞价/资金流向/研报列表
优先级3 (补全):  东方财富 → 结构化财务数据/板块资金
优先级4 (增量):  新浪财经 → 实时新闻/行情备选

故障切换策略：
  同花顺 K线不可用 → 自动切换东方财富 K线接口
  新浪行情不可用 → 自动切换腾讯财经接口
  所有源都不可用 → 告警 + 标记数据缺失
```

## 4. 采集内容全景矩阵

| 内容大类 | 子类 | 主要数据源 | 存储目标 | Agent 使用场景 |
|----------|------|-----------|----------|----------------|
| **交易数据** | K线、分时、集合竞价、资金流向 | 同花顺/东方财富 | PostgreSQL(TimescaleDB) | 技术分析、资金情绪分析 |
| **财务数据** | 资产负债表、利润表、现金流量表 | 巨潮资讯/东方财富 | PostgreSQL | 基本面分析、估值模型 |
| **财报文件** | PDF 年报/半年报/季报 | 巨潮资讯 | MinIO + Milvus 向量库 | 财报分析 Agent RAG |
| **研报文件** | 券商研报 PDF | 同花顺/东方财富 | MinIO + Milvus 向量库 | 研报摘要 Agent |
| **公司公告** | 临时公告、重大事项 | 巨潮资讯 | PostgreSQL + ES | 事件驱动分析 |
| **新闻舆情** | 个股新闻、行业新闻 | 新浪财经 | Elasticsearch | 热点追踪、情绪分析 |
| **公司治理** | 股东、高管、股本结构 | 巨潮资讯 | PostgreSQL | 公司画像 |
| **行业数据** | 板块涨跌、产业链信息 | 同花顺/东方财富 | PostgreSQL | 产业链分析 Agent |
