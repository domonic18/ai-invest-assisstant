# AI Invest Assistant — 需求文档

## 1. 文档概述

### 1.1 文档目的

本文档定义 **AI 智能投研数据平台**（AI Invest Assistant）的需求规格，包括项目背景、目标用户群体、核心功能需求和功能边界，作为后续设计、开发和验收的基准。

### 1.2 适用范围

- 产品设计团队：理解产品定位、用户画像、功能范围
- 开发团队：明确功能需求的技术实现目标
- 测试团队：制定测试用例与验收标准

### 1.3 术语说明

| 术语 | 说明 |
|------|------|
| SCF | 腾讯云 Serverless Cloud Function，无服务器函数计算 |
| AI Skill | 基于自然语言描述的分析指令文件（SKILL.md），由 Python Agent SDK（PydanticAI / OpenAI Agents SDK）加载并执行 |
| 产业链 | 行业上下游企业组成的供应链和价值链网络 |
| 资金流向 | 板块/个股层面的主力资金流动数据，系统以动态动效呈现资金在不同板块间的迁徙路径和轮动节奏 |
| 集合竞价 | 开盘前（9:15-9:25）的集中撮合阶段，系统支持对历史竞价数据进行时间范围回看和多日叠加分析 |
| 复盘 | 对历史交易数据的系统性回顾与分析，包含竞价回看、资金流向动画、板块轮动等维度 |
| 工作台 | 登录后默认聚合首页，汇总投资日历摘要、复盘核心结论、要闻资讯、自选股概览等关键信息 |
| 投资日历 | 影响投资决策的事件日程集合：宏观经济数据披露、央行议息、新股/解禁、重要会议、财报披露及 AI 衍生事件 |
| 跟踪指数 | 大盘页与工作台展示的行情指标清单（A 股指数 + 黄金/美债收益率/美元指数等全球指标），全局动态可配 |
| Milvus | 开源向量数据库，用于研报/财报语义检索和知识库 |
| API-KEY | 用户身份凭证，用于通过 MCP 接口调用平台 AI 分析能力，每个用户可创建和管理自己的 API-KEY |
| MCP (Model Context Protocol) | 开放协议标准，允许外部 AI 工具（如 Claude Desktop、Cursor 等）通过标准化接口调用平台的数据和分析服务 |
| 后台管理 | 系统管理端（Admin），提供对用户、API-KEY、股票、研报、新闻等核心数据的图形化管理界面（CRUD） |

## 2. 项目背景

### 2.1 行业背景

中国 A 股市场拥有超过 5000 家上市公司，每日产生海量交易数据、公告、财报和研究报告。个人投资者和中小型投资机构在信息获取和分析过程中面临以下痛点：

1. **信息碎片化**：行情数据、财务数据、研报、新闻分散在不同平台，需要手动切换多个工具
2. **分析门槛高**：产业链分析、财务建模、估值计算等深度分析需要专业知识，散户难以独立完成
3. **时效性不足**：盘中热点、集合竞价信号、突发新闻等关键信息窗口期短，人工跟踪容易错过
4. **移动端体验差**：传统投研工具以 PC 端为主，移动端功能简化严重，不利于随时随地查看

### 2.2 项目目标

构建一个全链路智能投研平台，实现：

- **数据采集自动化**：定时从公开数据源采集行情、财报、研报、新闻，完成清洗和标准化入库
- **分析智能化**：基于 AI Agent（Python Agent SDK + Skill 体系）自动完成产业链分析、研报摘要、热点发现、财务体检等深度分析任务
- **展示多端化**：提供 Web 端（完整交互式图表）和微信小程序（核心数据速览）双端访问体验
- **部署轻量化**：基于腾讯云 SCF + 轻量服务器，实现弹性伸缩和低成本运维

### 2.2.1 核心竞争力

本系统区别于传统炒股软件（如同花顺、东方财富）和 Wind 终端的核心竞争力集中在两个维度：

**竞争力一：交易复盘能力**

传统软件仅提供当日盘面数据，缺乏系统性的复盘工具。本平台提供：

- **集合竞价复盘**：支持用户选择任意时间范围（日/周/月），批量回看历史集合竞价数据（撮合价格走势、未匹配量变化、竞价量能异动），快速对比不同交易日的竞价特征
- **资金流向动态追踪**：不仅仅是静态热力图，而是通过动态动效展示板块间资金的流入/流出流向、轮动节奏和切换信号，让用户直观感知市场资金的"迁徙路径"

**竞争力二：深度产业链洞察**

传统软件的产业链分析往往停留在概念板块的简单罗列，本平台提供基于 AI 的全景式产业链分析：

- **全维度产业链解剖**：覆盖上游原材料、中游制造/设备/工具、下游应用场景的完整链条，每个环节识别出 3-5 家核心标的
- **多维度环节对比**：各环节的毛利率、净利率、营收增速、研发投入占比、议价能力的交叉对比
- **图谱定期自动更新**：系统每周/每月自动触发 AI 分析最新研报和财报，自动刷新产业链数据（财务指标、核心标的、国产化率），保留历史版本供对比
- **动态变化感知**：追踪并展示每个核心标的近期发生的重大动态（技术突破、产能扩张、政策变化、评级调整），帮助用户理解产业链正在发生的变化
- **核心标的 AI 提醒**：当产业链核心标的出现财报异动、评级集中调整、技术突破等关键事件时，AI 主动生成提醒通知，帮助用户第一时间感知产业链关键变化
- **价值分布与瓶颈识别**：自动标注产业链中利润最集中的环节和存在"卡脖子"风险的环节

### 2.3 与同类产品的差异

| 维度 | 传统投研工具 | Wind/同花顺 iFinD | AI Invest Assistant |
|------|-------------|-------------------|---------------------|
| 数据源 | 单一或接入成本高 | 专业终端，收费昂贵 | 公开数据聚合，免费使用 |
| AI 分析 | 几乎没有 | 基础搜索/筛选 | Skill + Python Agent SDK 驱动，语义级分析 |
| 产业链 | 静态图谱 | 静态图谱 | AI 动态生成 + 价值分布 + 瓶颈识别 |
| 移动端 | 功能阉割严重 | 专业终端无移动版 | 小程序精选核心功能，体验统一 |
| 部署 | - | 本地安装客户端 | 全云端部署，开箱即用 |
| 维护成本 | 低 | 年费 ¥40,000+ | SCF 弹性计费，低用量低成本 |

### 4.2 数据采集功能

#### F-DC-01 行情数据采集

- **描述**：定时采集 A 股全市场日 K 线、周 K 线、月 K 线、分钟级行情数据
- **数据来源**：akshare / 东方财富 API
- **采集频率**：交易日盘后（日 K）、盘中每 5 分钟（分钟级）
- **关键字段**：开盘价、收盘价、最高价、最低价、成交量、成交额、换手率、涨跌幅

#### F-DC-02 财报数据采集

- **描述**：采集上市公司季报/年报财务数据（资产负债表、利润表、现金流量表）
- **数据来源**：巨潮资讯(cninfo)、东方财富
- **采集频率**：财报发布后 24 小时内
- **存储格式**：结构化数据入库（PostgreSQL）+ PDF 原文存 MinIO

#### F-DC-03 研报数据采集

- **描述**：采集券商研究所发布的行业/个股研报 PDF
- **数据来源**：东方财富研报中心
- **采集频率**：每日早 8:00
- **处理流程**：PDF 下载 → 文本抽取 → Milvus 向量化入库 → ES 全文索引

#### F-DC-04 新闻与公告采集

- **描述**：采集上市公司公告、财经新闻、行业动态，以及财联社电报 7×24 高频快讯
- **数据来源**：巨潮资讯、新浪财经、财联社电报（cls.cn telegraph）
- **采集频率**：公告盘中每 15 分钟、盘后每 30 分钟；财联社电报准实时（驻留进程 10 秒增量轮询）
- **财联社电报准实时通道**（区别于常规定时抓取）：官方无推送 API/WebSocket，页面"实时"本身即前端 10 秒轮询增量接口（`lastTime` 游标、仅取新增）。采集侧以同节奏驻留进程模拟真实用户行为：`sign = MD5(SHA1(参数按 key 字母序拼接))` 签名 + Chrome TLS 指纹 + WAF Cookie 管理 + `sv` 版本号自动提取；延迟 ≤10 秒、单次请求仅取增量，兼顾及时性与风控友好；游标断点续传、失败指数退避、看门狗补漏
- **处理流程**：去重（电报按 cls 消息 id 幂等）→ 分类（公告/新闻/快讯/行业）→ ES 入索引

#### F-DC-05 投资日历事件采集

- **描述**：采集影响投资决策的日程类事件，形成统一的投资日历数据底座（展示见 F-VIS-07）。事件分三类：
  - **财联社投资日历**：A 股新股/解禁/经济数据披露/重要会议等（cls.cn investkalendar）。其接口带 `sign` 签名与 WAF 风控，实施时需逆向签名机制或解析其每月"资本市场大事提醒"栏目文章——**数据源调研项**
  - **权威固定日程**：美联储 FOMC 议息会议年度日历（federalreserve.gov）、美国 CPI/非农等 BLS 公布日程（bls.gov/schedule），每年初发布一次，结构稳定，半自动导入 + 人工校对
  - **（远期）平台衍生事件**：用户自选股财报披露日期自动关联、AI 从财报提取的关键事件（F-AI-08）
- **数据来源**：财联社 cls.cn、美联储官网、美国劳工统计局（BLS）
- **采集频率**：财联社日历每日增量采集；权威日程每年初导入一次
- **存储**：PostgreSQL `invest_calendar_event` 表（事件时间、标题、分类、影响市场、来源、关联标的）

#### F-DC-06 全球跟踪指标行情采集

- **描述**：采集 A 股指数之外的全球跟踪指标行情，支撑动态跟踪指数清单（F-VIS-08）。首批指标：黄金（COMEX 期金/伦敦金现）、美债 2 年期收益率、美债 10 年期收益率、美元指数（DXY）
- **数据来源**（候选，实施前逐一验证）：
  - 美债收益率：Tushare `us_tycr` 接口（美国国债收益率曲线，渠道已接，需确认积分权限）
  - 美元指数/全球指数/黄金：东方财富全球指数与行情中心接口（akshare `index_global_spot_em` / `index_global_hist_em` 可作参考实现）；注意东财 WAF 指纹限流约束，优先走 push2delay 镜像或低频采集
  - 兜底：Yahoo Finance（`^TNX` / `DX-Y.NYB` / `GC=F`，境内可达性需验证）
- **采集频率**：交易日盘中低频定时 + 盘后收盘价落库
- **关键字段**：指标代码、名称、最新价、涨跌幅、开盘/收盘、数据时间

### 4.3 AI 分析功能

#### F-AI-01 产业链图谱分析

- **描述**：对指定行业进行完整的上下游产业链深度剖析，全维度展示产业链结构、各环节价值分布、核心标的及动态变化。图谱由 AI 定期分析研报和财报数据自动更新，并在核心标的发生重大事件时主动提醒用户。是本系统核心竞争优势
- **触发方式**：用户在 Web 端输入行业名称（如"半导体"、"新能源汽车"），系统生成初始图谱；后续图谱定期自动刷新
- **图谱定期更新机制**：
  - **更新触发条件**：
    - 定时自动更新：每周/每月自动触发 AI 重新分析最新研报和财报，刷新产业链数据结构
    - 重大事件触发更新：当系统检测到产业链核心标的发布财报（季报/年报）、重大公告、或批量券商研报发布时，自动触发增量更新
    - 用户手动触发：用户可在页面点击"刷新分析"，立即使用最新数据重新生成图谱
  - **更新内容范围**：
    - 财务数据刷新：各环节核心标的毛利率、净利率、营收增速、ROE 等指标基于最新财报更新
    - 核心标的变化：根据最新研报和行业数据，调整各环节的代表性公司（新增/移除/替换）
    - 国产化率重新评估：基于最新产业链调研和公司公告更新各环节国产化率
    - 动态事件追加：将新发现的技术突破、产能扩张、政策变化追加到图谱节点的事件标签中
  - **版本管理**：
    - 每次更新生成新版本图谱，保留历史版本快照
    - 用户可切换查看不同时期的产业链图谱版本（如"2026年Q1版本" vs "2026年Q2版本"）
    - 版本对比视图：高亮标注两个版本之间的差异（新标的、淘汰标的、指标变化方向）
  - **数据来源自动采集**：
    - 财报数据：从 PostgreSQL 中自动拉取核心标的的最新财务数据
    - 研报数据：定期触发研报采集任务，对新增研报进行 AI 摘要和观点提取
    - 新闻与公告：监控核心标的的公告和行业新闻，提取关键事件
    - 向量知识库：从 Milvus 中检索与产业链各环节相关的最新研报片段，提取产业链结构变化信息
- **核心标的 AI 提醒**：
  - **提醒触发条件**（由 AI 定期分析财报和研报后自动判断）：
    - **财报异动提醒**：当核心标的发布季报后，AI 自动分析并与历史数据对比，若毛利率波动超过 ±5%、营收增速变化超过 ±20%、或出现净利润由盈转亏等重大变化，生成提醒通知
    - **评级调整提醒**：当 3 家以上券商在同一周内调整核心标的评级时（集体上调/下调），AI 分析评级变化背后的共识逻辑，生成提醒通知
    - **技术突破提醒**：当核心标的发生产品认证通过、新产线投产、重大合同签订等里程碑事件时，AI 评估其对产业链格局的影响，生成提醒通知
    - **产业链格局变化提醒**：当某个环节出现新的重要参与者（新上市公司、跨界进入者），或某个环节集中出现产能扩张/收缩信号时，AI 判断该环节竞争格局是否发生变化，生成提醒通知
    - **政策催化提醒**：当国家/地方出台与产业链相关的重大政策（产业扶持、出口管制、补贴政策等）时，AI 分析其对产业链各环节的影响方向和程度
  - **提醒输出形式**：
    - Web 端：在产业链图谱页面顶部展示"提醒面板"，按重要程度排序，每条提醒包含触发条件说明、影响环节、建议关注的标的
    - 通知中心：系统全局通知中心汇总所有提醒，用户点击可跳转到对应的产业链图谱节点
    - 邮件/小程序推送（可选）：用户可订阅特定行业的提醒推送
  - **提醒时效性**：
    - 财报异动：季报发布后 24 小时内生成提醒
    - 评级调整：检测到后 12 小时内生成提醒
    - 技术突破/政策催化：检测到后 6 小时内生成提醒
  - **提醒管理**：
    - 用户可设置提醒偏好（选择关注的行业、提醒类型开关）
    - 已读/未读状态管理
    - 提醒历史可追溯查看
- **产业链结构覆盖**（以半导体为例）：
  - 上游：硅材料、电子特气、光刻胶、靶材、CMP 抛光材料、湿电子化学品、石英材料、封装基板
  - 中游：半导体设备（刻蚀/薄膜沉积/光刻/清洗/检测）、晶圆制造（代工/IDM）、封装测试、EDA 工具/IP 核
  - 下游：AI 服务器、消费电子、汽车电子、工业控制、通信基站、物联网设备
- **每环节分析内容**：
  - 3-5 家核心标的（代码、名称、市值、所属细分领域）
  - 毛利率、净利率、营收增速、研发投入占比
  - 议价能力评分（应收账款周转率、预收账款占比、行业集中度 CR5）
  - 国产化率评估
  - 技术壁垒等级（高/中/低）
- **多维度交叉对比**：
  - 各环节毛利率对比排序（价值分布分析）
  - 各环节营收增速对比（成长性分析）
  - 各环节议价能力对比（话语权分析）
  - 各环节毛利率 × 国产化率象限图（投资机会矩阵）
- **动态变化感知**：
  - 自动追踪每个核心标的近期公告、新闻、研报评级变化
  - 标注近期发生重大变化的公司（如技术突破、产能扩张、政策利好、评级调整）
  - 以"近期动态"标签形式展示在产业链图谱中
  - 支持按时间范围筛选动态（近 7 天 / 近 30 天 / 近 90 天）
- **瓶颈与机会识别**：
  - 利润最集中的环节（价值洼地标注）
  - 国产化率最低的环节（替代机会标注）
  - 存在"卡脖子"风险的环节（风险预警标注）
  - 政策重点支持的环节（政策红利标注）
- **输出形式**：交互式产业链全景图谱（Web 端 AntV/G6）+ 各环节详细数据表格 + 版本切换器 + AI 提醒面板 + AI 结构化分析报告
- **可用端**：Web 端（完整）、小程序端（精简摘要 + 提醒推送）

#### F-AI-04 财务体检

#### F-AI-05 产业链突破点追踪

#### F-AI-06 集合竞价复盘

- **描述**：提供指定时间范围内的集合竞价数据回看与统计分析，帮助用户系统性地复盘竞价阶段的量价信号。是本系统交易复盘能力的核心组成部分
- **触发方式**：用户选择时间范围（近 1 天 / 近 5 天 / 近 20 天 / 自定义范围），系统批量加载对应交易日的集合竞价数据
- **时间范围查询**：
  - 预设快捷选项：最近 1 个交易日、最近 5 个交易日、最近 20 个交易日
  - 自定义日期范围选择器
  - 支持按周/月聚合统计
- **分析维度**：
  - 撮合价格走势回看（多日叠加对比，9:15-9:25 逐分钟）
  - 未匹配量变化趋势（多日对比）
  - 竞价量能异动检测（对比历史均值，标注异常交易日）
  - 各交易日竞价特征标签（放量竞价 / 缩量竞价 / 尾段异动 / 平稳竞价）
  - 关键股票竞价异动列表（按交易日组织）
- **输出形式**：
  - 多日竞价走势叠加图（不同颜色区分交易日）
  - 竞价量能统计表（日均成交量、量比、异常标记）
  - 关键股票异动汇总表
  - 支持导出为 CSV 格式
- **可用端**：Web 端 + 小程序端（核心功能，ec-canvas 渲染）

#### F-AI-07 自选股 AI 每日分析

- **描述**：每个交易日盘后对**开启 AI 复盘开关的自选股分组**（而非全部自选股）内的标的自动生成当日 AI 分析，输出固定三段式结构：
  - **盘面解读**：趋势状态（周线/日线均线关系、平台与箱体）、量能特征（缩量/放量、抛压/承接）
  - **操作策略**：条件触发式仓位动作（如"若放量突破某平台则补仓 X 成，否则持仓不动"）
  - **止损线**：关键均线/箱体位对应的减仓或清仓动作
- **触发方式**：交易日收盘后定时批量执行，仅遍历复盘开关开启的分组（heavy 队列，LLM 分钟级任务，单股串行避免并发限流）；结果按 `input_hash`（skill+code+日期）缓存，重复触发不重复消耗 LLM；未开启分组的标的不消耗 LLM
- **分析输入**：日/周 K 线与均线系统、成交量与换手率、所属行业/概念板块、近期公告与新闻标题
- **输出形式**：三段式结构化文本（Pydantic 校验），展示于个股详情 Tab 与自选股列表卡片；页面固定展示"AI 生成，不构成投资建议"免责声明
- **可用端**：Web 端

#### F-AI-08 财报 AI 衍生日历事件（远期）

- **描述**：AI 分析自选股/产业链核心标的的财报内容，提取关键技术突破、产能投产、里程碑规划等事件及其预计时间节点，自动写入投资日历（F-DC-05 / F-VIS-07），使日历从"外部日程"进化为"平台研究结论驱动"
- **触发方式**：财报采集完成并生成 AI 摘要后异步触发
- **归属版本**：V2.0+

### 4.5 用户功能

#### F-USER-01 自选股管理

- **描述**：用户可添加/删除自选股票，按分组管理

  - **AI 复盘分组开关**：分组级"AI 每日复盘"开关，仅开启的分组参与盘后 AI 每日分析（F-AI-07），其余分组不消耗 LLM

#### F-API-01 API-KEY 管理与 MCP 接口

- **描述**：提供用户 API-KEY 的创建、管理和撤销功能，并基于 MCP（Model Context Protocol）标准将平台的核心 AI 分析能力对外暴露为标准化接口，供外部 AI 工具无缝调用
- **触发方式**：用户在个人设置页面中管理 API-KEY；外部 AI 工具通过 MCP 协议接入
- **功能详情**：
  - **API-KEY 全生命周期管理**：
    - 用户在 Web 端"个人设置 → API-KEY"页面创建、查看、重命名、撤销 API-KEY
    - 每个用户最多拥有 5 个有效 API-KEY
    - API-KEY 创建时完整展示一次，之后不再明文展示（仅显示前缀 + 掩码）
    - 支持设置 API-KEY 的过期时间和权限范围（只读/读写）
    - 撤销后立即失效，不可恢复
  - **MCP 接口暴露**：
    - 平台作为 MCP Server 运行，暴露以下 Tool 能力：
      - `analyze_industry_chain` — 产业链图谱分析
      - `summarize_research_report` — 研报摘要提取
      - `detect_market_hotspots` — 市场热点追踪
      - `financial_health_check` — 上市公司财务体检
      - `track_chain_breakthrough` — 产业链突破点识别
      - `get_chain_alerts` — 获取产业链核心标的 AI 提醒列表
      - `get_chain_version` — 获取产业链图谱历史版本数据
      - `analyze_call_auction` — 集合竞价分析
      - `search_stock_info` — 股票基础信息查询
    - 提供 `list_mcp_resources` 和 `read_mcp_resource` 用于数据资源检索（研报、财报、行情数据）
  - **安全机制**：
    - 所有 MCP 请求必须携带有效 API-KEY（通过 HTTP Header `X-API-Key` 或 MCP 内置认证机制）
    - 支持 API-KEY 粒度的调用频率限制（默认 60 次/分钟）
    - 记录完整调用日志（调用方、时间、接口、参数、结果状态）
    - API-KEY 泄露时支持紧急撤销
  - **MCP 接入方式**：
    - 提供标准 MCP Server 配置文件模板，用户复制到 Claude Desktop、Cursor 等工具即可接入
    - 支持 SSE (Server-Sent Events) 传输协议，兼容主流 MCP 客户端
- **可用端**：Web 端（管理 API-KEY）、外部工具（MCP 调用）

#### F-USER-03 模型配置

- **描述**：允许用户在配置界面中自定义 AI 模型的服务地址、认证密钥和模型名称，从而使用自己偏好的大语言模型（如 OpenAI、DeepSeek、通义千问等）来驱动平台的 AI 分析功能（研报摘要、产业链分析、热点追踪等）
- **触发方式**：用户在 Web 端"个人设置 → 模型配置"页面进行配置
- **功能详情**：
  - **模型连接配置**：
    - 支持配置 `base_url`（模型 API 服务地址，如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1`）
    - 支持配置 `api_key`（用户自己的模型 API 密钥，加密存储）
    - 支持配置 `model`（模型名称，如 `gpt-4o`、`deepseek-chat`、`qwen-max`）
    - 支持配置多个模型，分别分配给不同分析场景（如研报分析用 GPT-4o、热点追踪用 DeepSeek）
  - **连接测试**：
    - 配置完成后提供"测试连接"按钮，发送轻量请求验证配置是否正确
    - 测试结果显示模型可用性和预估响应延迟
  - **默认模型**：
    - 系统内置默认模型配置，用户可在未配置时使用系统默认模型
    - 用户配置后自动切换为用户指定模型
  - **安全存储**：
    - `api_key` 在数据库中加密存储（AES-256-GCM）
    - 前端展示时脱敏处理（仅显示前 4 后 4 位）
    - 后端日志中自动过滤 api_key 字段，防止泄露
  - **回退机制**：
    - 用户配置的模型不可用时，自动回退到系统默认模型
    - 回退时向用户发送通知（Web 端提示 + 可选邮件通知）
- **可用端**：Web 端

#### F-ADMIN-01 后台管理

- **描述**：提供系统后台管理页面（Admin），支持管理员对平台各类核心数据进行图形化的增删改查（CRUD）操作，以及系统运行状态监控
- **触发方式**：管理员通过专用路径 `/admin` 登录后台管理系统
- **功能详情**：
  - **用户管理**：
    - 用户列表（搜索、分页、排序）
    - 查看用户详情（注册时间、最后一次登录时间、自选股数量等）
    - 启用/禁用用户账号
    - 重置用户密码
    - 查看用户 API-KEY 列表和调用统计
    - 设置用户角色（普通用户 / 管理员）
  - **股票数据管理**：
    - 股票基础信息管理（代码、名称、行业分类、上市日期等，支持新增/编辑/删除）
    - 行情数据管理（查看、补录、修正异常数据）
    - 财务数据管理（查看、手动导入、修正）
    - 支持批量导入（CSV 格式）
  - **研报管理**：
    - 研报列表（按股票、券商、日期筛选）
    - 研报上传（手动上传 PDF 文件）
    - 研报删除（同时清理 MinIO 文件和 Milvus 向量）
    - 研报 AI 摘要重新生成（手动触发）
  - **新闻与公告管理**：
    - 新闻/公告列表（搜索、分类筛选、时间范围筛选）
    - 单条新增/编辑/删除
    - 批量导入
    - 热点标签管理（添加/修改/删除热点标签）
  - **数据采集任务管理**：
    - 查看所有采集任务状态（运行中/成功/失败/待执行）
    - 手动触发采集任务
    - 查看采集任务执行日志
    - 暂停/恢复定时采集任务
    - 修改采集频率
  - **系统监控**：
    - 仪表盘展示关键指标（API 调用量、采集成功率、活跃用户数、存储使用量）
    - 查看系统运行日志（FastAPI 日志、Nginx 日志、采集日志）
    - 数据库连接状态监控
    - 中间件健康检查（PostgreSQL、Redis、ES、Milvus、MinIO）
  - **角色与权限**：
    - 角色分为"超级管理员"和"内容管理员"
    - 超级管理员：所有权限，包括用户管理、系统配置
    - 内容管理员：数据管理权限（股票、研报、新闻 CRUD），无用户管理和系统配置权限
  - **审计日志**：
    - 记录所有管理员操作（操作人、时间、操作类型、操作对象、变更内容）
    - 支持按时间范围和操作人筛选查询
    - 审计日志不可删除，保留至少 90 天
- **可用端**：Web 端（独立管理后台，不与普通用户前端共用路由）

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| Web 页面首屏加载 | < 3 秒 |
| API 响应时间（P95） | < 500ms（简单查询）/ < 10s（AI 分析） |
| 小程序包体积 | < 2MB |
| AI 分析任务执行 | < 5 分钟（产业链分析）/ < 30s（热点追踪） |
| 数据采集延迟 | 盘后数据 < 30 分钟 / 盘中数据 < 5 分钟 |

### 5.2 可用性要求

- 系统可用性 ≥ 99.5%（交易日 9:00-18:00）
- 小程序审核通过率目标：一次通过
- 支持至少 100 并发用户同时访问

### 5.3 安全要求

- 所有 API 启用 HTTPS/TLS
- 用户敏感数据（自选股列表、偏好）加密存储
- 数据采集遵守目标网站的 robots.txt 和使用条款
- 用户 API-KEY 和模型 API-KEY 使用 AES-256-GCM 加密存储，前端脱敏展示
- API-KEY 支持权限分级（只读/读写）和调用频率限制
- 后台管理操作完整记录审计日志，不可删除
- 不对个人用户展示投资建议，仅提供数据和分析工具

### 5.4 可维护性要求

- 系统采用模块化架构，数据采集、AI 分析、前端展示解耦
- AI 分析逻辑通过 Skill 文件（SKILL.md）维护，由 Python Agent SDK 加载执行，支持热更新
- 部署采用容器化方案（Docker），支持一键部署和回滚
- 日志和监控通过腾讯云日志服务 CLS 集中管理

## 6. 功能边界

### 6.1 明确包含

- A 股市场的行情、财报、研报、新闻（含财联社电报准实时快讯）数据采集和分析
- 基于公开数据的 AI 辅助分析（产业链、研报、热点、财务、集合竞价、自选股每日分析——后者输出盘面解读/操作策略/止损参考，附免责声明）
- 投资日历（财联社日历、FOMC/CPI 等宏观日程，远期含 AI 衍生事件）与工作台聚合首页
- 全球跟踪指标动态配置与行情采集（黄金、美债收益率、美元指数等）
- Web 端完整功能和微信小程序核心功能的双端覆盖
- 腾讯云 SCF + 轻量服务器的部署运维方案
- API-KEY 管理与 MCP 标准化接口，支持外部 AI 工具集成
- 用户自定义模型配置（base_url / api_key / model）
- 管理员后台系统（用户管理、数据 CRUD、系统监控）

### 6.2 明确不包含

- **不提供交易下单功能**：平台不接入券商交易接口，不执行买卖操作
- **不提供对外投资咨询服务**：AI 生成的盘面解读、操作策略与止损参考（F-AI-07）仅限平台内自用展示，固定附"AI 生成，不构成投资建议"免责声明，不构成对外的投资顾问服务
- **不覆盖港/美股**：V1 阶段仅支持 A 股市场（后续版本可扩展）
- **不做实时行情**：分钟级数据按 5 分钟间隔采集，非交易所级实时数据
- **不做量化回测**：不提供策略编写和回测功能
- **不做社区/社交**：不包含用户评论、发帖、跟单等社交功能
- **不提供付费订阅**：V1 阶段为免费工具，不接入支付系统

## 7. 版本规划

### 7.1 V1.0 — MVP（最小可行产品）

- 数据采集管道打通（行情 + 新闻 + 公告）
- 5 个核心 AI Skill 可用（产业链全景分析、研报摘要、热点追踪、财务体检、集合竞价复盘）
- Web 端上线（仪表盘 + 产业链全景分析 + 热点 + 集合竞价复盘 + 资金流向动态追踪）
- 小程序端上线（集合竞价复盘、热点速览、自选股）
- API-KEY 管理 + MCP 接口上线
- 后台管理系统上线（股票/研报/新闻 CRUD + 系统监控）
- 腾讯云 SCF + 轻量服务器部署

### 7.2 V1.1 — 增强分析

- 产业链突破点追踪上线
- 产业链图谱定期自动更新机制上线（定时更新 + 版本管理 + 版本对比）
- 核心标的 AI 提醒上线（财报异动、评级调整、技术突破、政策催化自动检测与推送）
- 资金流向桑基图上线
- 研报 PDF 全文在线阅读
- 用户自定义模型配置上线
- 自选股分组和自定义看板

### 7.3 V1.2 — 工作台与投资日历

- 工作台聚合页上线（F-VIS-06）：投资日历摘要 / 复盘核心结论 / 要闻资讯 / 自选股概览 / 市场快览，登录默认入口
- 投资日历上线（F-DC-05 + F-VIS-07）：财联社投资日历 + FOMC 议息 / 美国 CPI 等宏观日程（数据源调研项：cls.cn 签名接口逆向）
- 自选股分组落地（F-USER-01 补全：分组增删改查 + AI 复盘分组开关）
- 自选股 AI 每日分析上线（F-AI-07）：盘后定时批量生成（仅开启复盘开关的分组），三段式输出（盘面解读/操作策略/止损线）
- 财联社电报准实时采集上线（F-DC-04）：10 秒级增量轮询驻留进程，快讯入 ES 索引
- 动态跟踪指数上线（F-DC-06 + F-VIS-08）：黄金 / 美债 2Y·10Y 收益率 / 美元指数，全局可配管理

### 7.4 V2.0 — 扩展与优化

- 财报 AI 衍生日历事件（F-AI-08）：关键技术突破/里程碑时间自动入日历
- 自选股关键事件入日历：财报披露日期等自动关联
- 覆盖港/美股数据
- AI 分析报告自动推送（小程序订阅消息）
- 用户行为分析和个性化推荐
- 性能优化与稳定性提升
