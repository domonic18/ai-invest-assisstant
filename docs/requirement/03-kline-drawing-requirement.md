# K 线画线工具与 AI 智能画线 需求文档

> 版本：V1.0（2026-09-13 定稿）　状态：待排期
> 上位文档：[01-requirement.md](./01-requirement.md)（本文档为其「行情可视化域」图表标注能力的专项扩展，编号启用新域 `F-DRAW`，实施时回填 01 文档功能总览表）
> 原型：[docs/prototypes/kline-drawing.html](../prototypes/kline-drawing.html)（2026-09-13 定稿）

## 1. 文档概述

### 1.1 目的

技术分析中「画线」是核心工作流：箱体标注横盘整理区间、射线标注压力/支撑位、文字标注关键事件。当前系统 K 线图（个股/板块/大盘指数）**不具备任何画线能力**；同时 AI 复盘产出为纯文字（sections markdown），关键价位、形态边界只能靠文字描述，用户需自行在脑中换算到图上。本文档定义：

1. **用户画线**：在 K 线图上交互式绘制/编辑/管理画线，持久化保存，供自己复盘时反复使用；
2. **AI 双向读写**：Agent 能**读取**用户画线作为复盘上下文（让 AI 知道用户关注的形态）；Agent 能**绘制** AI 画线——仅由用户在侧边栏对话中主动触发（已定稿：定时复盘不画线），把分析结论中的压力/支撑/箱体直接画在图上，替代繁琐文字描述。

### 1.2 适用范围

- 覆盖图表：个股 K 线（StockChartView）、板块 K 线（复用 StockChartView）、大盘/全球指数 K 线（IndexKlineChart）
- 覆盖周期：日线 / 周线 / 月线（分钟线不提供画线）
- 覆盖 Agent 链路：**画线生成仅限侧边栏对话路径**（用户主动提出）；个股复盘 / 大盘综述仅**读取**画线作为上下文，不执行画线动作

### 1.3 术语表

| 术语 | 含义 |
|------|------|
| 画线（drawing） | 叠加在 K 线绘图区上的矢量标注，5 种类型之一 |
| 锚点（anchor） | 画线的定位点，用**数据坐标 (date, price)** 存储，非像素 |
| 严格隔离 | 画线归属含周期维度，各周期画线集完全独立、互不可见（已定稿） |
| 画线前确认 | Agent 执行画线前，若目标已有画线，以问题卡询问处理策略（变更/保留/删除/取消）后才动手（已定稿） |
| 采纳（adopt） | 将 AI 画线复制为可编辑的用户画线；原 AI 画线保留 |
| AI 画线 | Agent 经对话生成的画线，独立落表、全局共享，视觉上与用户画线区分 |
| 用户画线 | 用户手动绘制，per-user 私有 |

## 2. 现状梳理（2026-09-13 实证）

### 2.1 图表组件现状

| 事实 | 位置 | 影响 |
|------|------|------|
| 个股与板块共用 `StockChartView` 复合组件；大盘/全球指数用独立 `IndexKlineChart` | `web/src/components/charts/` | 画线渲染层需做成**独立图层组件**，两套组件分别接入，不可只接一处 |
| 周期切换是同一组件的 prop（daily/weekly/monthly + 分钟视图） | `StockChartView.tsx` | 画线集随周期 prop 切换重载，天然支持严格隔离 |
| 已有 markLine 先例（异动日竖虚线 markers 入参），无 markArea/graphic 使用 | `klineOption.ts` | 画线需引入 ECharts graphic 原语 + 像素↔数据坐标换算，属新增能力 |
| K 线数据类型 `KlineData{date,open,high,low,close,...}`，类型中无画线字段 | `shared/types/stock.ts` | 需新增画线 wire 类型（shared 单一真相源） |

### 2.2 AI 链路现状

- AI 产出统一落 `ai_analysis_result`（`structured_output` JSONB，`skill_id` 区分），复盘输出为 `{sections:{key:markdown}}` 纯文字；**画线不应混入复盘展示 schema**（已定稿独立落表）
- 「侧边栏 Agent 触发 + page_event 回写」通道成熟（`pageEvents.ts` 注册表 + `usePageAssistantResult`），AI 画线回写可复用
- 定时复盘链路：celery → internal 采集器 → 服务层（redis 锁 + 缓存）——本需求中该链路仅**注入画线上下文**（读取），不生成画线（已定稿）
- **无任何用户标注/画线/笔记类表**，需新建

## 3. 用户与场景

| 场景 | 描述 | 频次 |
|------|------|------|
| 技术复盘标注 | 复盘时在日线图画箱体（横盘整理区）、压力/支撑射线、关键事件文字，次日/次周打开仍在 | 每交易日 |
| AI 复盘引用画线 | 触发个股复盘时，AI 读取已画箱体/射线，叙述直接引用（"你标注的箱体上沿 1520 元"） | 每交易日 |

## 4. 核心模型（设计核心）

### 4.1 画线类型与锚点语义（一期 5 种）

| 类型 | 锚点 | 语义 |
|------|------|------|
| 趋势线段 `trendline` | 2 × (date, price) | 两点线段，不延伸 |
| 射线 `ray` | 2 × (date, price) | 两点定方向，自第二锚点向右延伸至绘图区右缘（压力/支撑线）；支持向左 `left`/双向 `both`，默认 `right` |
| 水平线 `hline` | 1 × price | 全宽水平线，常配合文字标注价位 |
| 箱体 `box` | 2 × (date, price) | 矩形区域：上下沿 = 价格区间，左右边界 = 日期区间；半透明填充 |
| 文字标注 `text` | 1 × (date, price) | 锚点处文字标签 |

**锚点对齐规则**：锚点存储为数据坐标 `(date, price)`；渲染时 date 对齐到当前周期 bar 序列中「≤ 该日期的最后一根 bar」（周/月线锚点日期落入该周期 bar 区间即归属该 bar）。数据坐标保证**新 K 线追加、缩放、跨设备渲染下画线语义稳定**——这是画线可被 Agent 结构化读写的前提。

### 4.2 归属与隔离模型

| 维度 | 用户画线 | AI 画线 |
|------|----------|---------|
| 归属键 | `(user_id, target_type, target_code, period)` | `(target_type, target_code, period)`（每标的每周期一套 AI 画线集） |
| target_type | `stock` / `index` / `sector` | 同左 |
| 周期 | **严格隔离**：各周期画线集完全独立，切换周期互不可见（已定稿，不做跨周期同步选项） | 同左 |
| 可见性 | 仅创建者本人 | **全局共享**（分析产出为系统级沉淀，无用户私有语义） |
| 人工编辑 | — | **支持原位编辑**（拖拽锚点/改文字/删除单条），直接落表（可变工作区语义） |
| 生命周期 | 用户手动增删改，长期保留 | 仅由对话触发生成/调整：生成前经**画线前确认**，按用户选择的策略（变更/保留/删除）整组更新；无定时自动覆盖 |

### 4.3 样式模型

| 属性 | 取值 | 默认 |
|------|------|------|
| 颜色 | 调色板 6 色（与涨跌配色方案无关，画线色独立） | 最近使用色记忆 |
| 线型 | 实线 / 虚线 / 点线 | 实线 |
| 线宽 | 1 / 2 / 3 px | 2 px |
| 填充（仅箱体） | 固定低透明度 | 跟随颜色 |
| 文字 | 画线携带的标注文案（box/text 必有，射线/水平线/趋势线可选） | — |

**AI 画线视觉区分**（固定，不可由模型指定颜色样式）：虚线 + 半透明 + 锚点处 `AI` 角标徽标；hover tooltip 展示 `label`（画线名）与 `reason`（归因说明，如"6-08 与 7-22 高点连线，两次受阻"）。

**AI 画线人工编辑**（已定稿：人可直接编辑修改）：

- AI 画线可原位编辑：拖拽锚点调整位置、双击改 label 文字、单条删除；**直接落表**（AI 画线集为可变工作区，生成仅由用户对话触发，无自动覆盖，故编辑无需合并标记）
- 样式契约：AI 图层颜色/线型锁定（保证一眼可辨）；需完全自定义样式 → 走「采纳」转为用户画线

### 4.4 Agent 双向协议

**读（用户画线 → Agent 上下文）**：分析某标的时，注入该标的**全部周期**的用户画线（UI 显示严格隔离，Agent 读取不隔离——给模型全量信息）。序列化为紧凑文字块：

```
[用户画线·日线]
- 箱体：1450.00~1520.00 元（2026-05-06 ~ 2026-08-14）「横盘整理」
- 射线（压力）：2026-06-09 1483.00 → 向右延伸「压力线」
[用户画线·周线]
- 水平线：1380.00「前低支撑」
```

注入点：① 个股复盘服务（`stock_daily_analysis`）输入上下文；② 大盘综述服务（对应指数画线）；③ 侧边栏查询工具（见 F-DRAW-06）。画线为空时注入空提示，不阻断复盘链路。

**写（Agent → AI 画线，仅侧边栏对话路径，已定稿）**：

```json
{"drawing_type": "ray", "period": "daily",
 "anchors": [{"date": "2026-06-09", "price": 1483.0}, {"date": "2026-07-22", "price": 1512.5}],
 "direction": "right", "label": "压力线", "reason": "两高点连线，两次受阻回落"}
```

- Agent 经 `kline-smart-drawing` skill 分析后，调 `persist_ai_kline_drawings(mode, drawings[])` 工具整组写入 `ai_kline_drawing`，并构造 `page_event("kline_drawing.complete", ...)` 回写前端刷新 AI 图层
- `mode` 由**画线前确认**的用户选择决定：`replace`（变更/删除后重画）/ `append`（保留并新增）；无已有画线时默认 `replace`
- 定时复盘路径**不画线**（已定稿）：复盘 skill 的输出 schema 不扩展 drawings，复盘只读画线上下文

**画线前确认（ask-user 问题卡）**：Agent 执行画线前必须先 `get_kline_drawings` 检查目标标的当前周期是否已有画线；已有画线时，**不得直接动手**，以问题卡结束本轮询问处理策略：

| 选项 | 行为 |
|------|------|
| 变更已有 | 在现有画线基础上调整（`replace` 全量重画，可指定仅调整某几条） |
| 保留并新增 | 已有画线不动，新画线追加共存（`append`） |
| 删除后重画 | 清除已有后重画（须明确范围：仅 AI 画线 / 含用户画线；删用户画线必须二次确认） |
| 取消 | 本次不画线 |

- 机制：问题卡为**本轮收尾型**交互——Agent 以结构化问题（问题文本 + 选项列表 + 默认建议项）结束本轮，前端侧边栏渲染为选项按钮，用户点击后选项作为用户消息续跑线程；复用既有 SSE 链路，不引入长连接暂停复杂度。该机制为通用底座，后续其他交互式 skill 可复用

## 5. 功能需求

### 5.1 F-DRAW-01 画线工具与交互

- **描述**：图表工具栏新增「画线」模式开关；开启后显示 5 类型子工具条。交互：箱体/射线/趋势线 = 按下-拖动-松开；水平线/文字 = 单击定位（文字弹输入框）
- **编辑**：点击画线选中（命中检测：线段距离阈值/矩形内部/文字包围盒）；锚点拖拽改形态、整体拖拽平移、双击文字改文案、Delete 删除
- **约束**：画线模式与缩放（dataZoom）互斥——画线模式下滚轮/拖动不触发缩放；绘图交互不得影响既有十字光标/键盘导航在非画线模式下的行为
- **原型**：`kline-drawing.html` 区块 ①②

### 5.2 F-DRAW-02 样式快速配置

- **描述**：选中画线时绘图区内浮动样式条：6 色板 / 线型三选 / 线宽三档 / 文字编辑 / 删除，改动即时生效并持久化
- **默认样式记忆**：新画线初始颜色记最近使用色；线型/线宽默认值在画线面板设置点记忆（localStorage per user）

### 5.3 F-DRAW-03 持久化与周期严格隔离

- **描述**：画线实时落库（创建/修改/删除即保存，无手动保存动作）；按 4.2 归属键隔离。刷新、重登、跨设备后画线恢复
- **关键规则**：切换周期 → 画线集整体切换为该周期集合；锚点 date 按 4.1 对齐规则渲染；数据坐标保证 K 线追加后画线不漂移
- **验收注**：同一标的日线画的箱体，切到周线不可见，切回日线完整恢复

### 5.4 F-DRAW-04 画线清单管理面板

- **描述**：图表侧画线面板，两个分组：**用户画线**（类型图标 + 文字摘要 + 单条显隐 eye + 删除）与 **AI 画线**（来源徽标 skill 名 + 生成日期 + reason 摘要 + 采纳按钮 + 清除全部）。面板顶部：当前周期提示 + 全部显隐开关
- **AI 图层开关**：一键显示/隐藏 AI 画线图层（独立于用户画线显隐）
- **原型**：`kline-drawing.html` 区块 ④

### 5.5 F-DRAW-05 多标的接入

- **描述**：个股（StockChartView）与大盘/全球指数（IndexKlineChart）、板块（SectorChartArea→StockChartView）三处接入同一画线图层组件；画线数据按 `target_type + target_code` 天然隔离
- **约束**：画线图层组件与 option 构建解耦（`components/charts/drawing/` 独立模块），两套图表组件以组合方式接入，不复制交互逻辑

### 5.6 F-DRAW-06 Agent 读取画线（复盘上下文注入）

- **描述**：按 4.4 读协议注入；新增侧边栏工具 `get_kline_drawings(target_type, target_code)`（返回全周期画线结构化 JSON），登记进 `build_assistant_tools()`
- **接线**：个股复盘服务输入上下文增加「用户画线」节；大盘综述注入对应指数画线；个股复盘/大盘综述 SKILL.md 输入说明与 prompt.yaml 增加画线解读指引（识别箱体/压力支撑并纳入叙述）
- **健壮性**：画线注入失败（查询异常）降级为无画线上下文，复盘照常生成

### 5.7 F-DRAW-07 Agent 智能画线（写，仅对话触发）

- **描述**：新 skill `kline-smart-drawing`，**仅侧边栏对话路径**（页面按钮预置问句「帮我画出当前标的的关键压力/支撑与形态边界」/ 对话自由触发；定时复盘不画线）。流程：`get_kline_drawings` 检查已有画线 →（已有则先出画线前确认问题卡，见 4.4）→ 取数分析 → `persist_ai_kline_drawings` 写表并回 `__event__`
- **ask-user 问题卡机制**：新增通用「问题卡」交互——Agent 以结构化问题结束本轮（含选项/默认建议），前端侧边栏渲染选项按钮，点击即作为用户消息续跑；该机制为独立底座能力，登记进 assistant 交互范式，供后续交互式 skill 复用
- **关键规则**：AI 画线样式由前端固定渲染（4.3），模型只输出类型/锚点/label/reason；锚点必须引用真实存在的 bar 日期；删除用户画线必须用户明确确认范围，Agent 不得静默清除用户画线

### 5.8 F-DRAW-08 AI 画线图层、人工编辑与采纳流

- **描述**：AI 画线渲染为独立图层（视觉区分见 4.3）；hover 显示 label + reason tooltip
- **人工原位编辑**：AI 画线可被直接选中编辑——拖拽锚点调整位置、双击改 label 文字、Delete 删除单条；改动**直接落表**（AI 画线集为可变工作区，无自动覆盖冲突）；颜色/线型锁定（AI 视觉契约），需完全自定义样式 → 走「采纳」
- **采纳**：单条「采纳」→ 复制为用户画线（默认样式）并可完全自定义，原 AI 画线保留
- **清除**：「清除 AI 画线」清空 AI 图层（对话重新生成即可恢复）
- **事件**：`kline_drawing.complete` 经 pageEvents 注册表接线（parse 画线数组 → 指向当前标的图表页路由）

### 5.9 数据模型（两表，幂等 SQL 迁移）

**`user_kline_drawing`**（用户态，per-user 私有）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL PK | |
| user_id | BIGINT FK | 归属用户 |
| target_type | VARCHAR(16) | stock / index / sector |
| target_code | VARCHAR(16) | 6 位代码或指数/板块代码 |
| period | VARCHAR(8) | daily / weekly / monthly |
| drawing_type | VARCHAR(16) | trendline / ray / hline / box / text |
| payload | JSONB | 锚点 + direction + style + text（4.1/4.3 结构） |
| created_at / updated_at | timestamptz | 审计字段 |

索引：`(user_id, target_type, target_code, period)`

**`ai_kline_drawing`**（AI 产出，全局共享，可变工作区语义——每标的每周期一套画线集）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL PK | |
| target_type / target_code / period | 同上 | 归属标的+周期 |
| skill_id | VARCHAR(64) | 最近一次生成来源（kline-smart-drawing） |
| trade_date | DATE | 最近一次生成对应交易日（展示用） |
| drawings | JSONB | 数组：[{drawing_type, anchors, direction?, label, reason}]（label 组内唯一，面板定位用） |
| summary | TEXT | 本组画线一段话说明（面板展示） |
| created_at / updated_at | timestamptz | 审计字段 |

唯一约束：`(target_type, target_code, period)` → 对话触发生成时按用户确认的策略整组 replace/append；人工原位编辑直接更新 drawings

## 6. 非功能需求

| 项 | 要求 |
|----|------|
| 权限 | 用户画线端点登录即可、per-user 强隔离（查改删校验归属）；AI 画线读全局共享、写仅 Agent/服务层 |
| 性能 | 画线清单接口 ≤100ms（单标的画线量级为几十条）；绘制/拖拽交互不掉帧（graphic 增量重绘，非整图 setOption） |
| 时区 | 锚点 date 为北京交易日历日（`app.core.clock` 口径）；payload 不存时间戳 |
| 可用性 | 画线图层异常不得影响 K 线主图渲染与既有交互；渲染失败静默降级 + 控制台告警日志 |
| 数据语义 | 锚点为数据坐标，任何缩放/数据更新下语义稳定；禁止像素坐标落库 |

## 7. 功能边界

**包含**：5 类画线的绘制/编辑/样式/持久化、清单管理、三处图表接入、Agent 读（复盘注入 + 查询工具）、Agent 写（对话 skill + 定时复盘扩展）、AI 图层与采纳流
**不包含**：分钟线画线、跨周期同步/显示（严格隔离已定稿）、斐波那契回撤/平行通道/甘氏线等扩展类型（后置）、画线分享/协作/评论、自动形态识别的传统"智能画线库"（AI 画线由 LLM 语义判断）、移动端画线（后置只读展示）、AI 画线历史版本回看（需另立历史表，触发条件立项）
