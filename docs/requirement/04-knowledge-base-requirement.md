## 1. 文档概述

### 1.1 背景与目的

平台已具备完整的 AI 分析能力（每日复盘、涨停归因、异动检测等），但分析方法论完全依赖内置技能文件中沉淀的通用知识，缺乏**体系化投资方法论**的供给。现有温成老师讲解趋势理论的**多集系列视频课程**，其中蕴含完整的知识体系（概念定义、判断规则、操作纪律、案例讲解）。本需求将该视频课程转化为**结构化、可检索、可被 Agent 引用与学习的知识库**，并提供两类核心服务：

1. **项目内知识检索**：在平台内搜索、浏览温成老师的知识点，按问题**精准定位到视频关键讲解位置**（集数 + 句级时间区间），用内置播放器回看片段；视频全程防盗下载
2. **Agent 知识供给**：
   - **运行时引用**：Agent 在复盘、异动等分析中检索知识库，让结论带上趋势理论依据（可溯源到视频时间点）
   - **自主优化技能**：Agent 对照知识库审查现有技能定义，自主产出优化建议，经人工审核后生效——让技能随知识库的完善而持续进化

知识库的建库全流程（登记课程、上传视频、转写、知识点审核、索引构建）均在**后台管理系统**内完成并触发。

### 1.2 适用范围与用户

- **面向用户**：管理员（后台全链路操作与审核）；预留「知识库授权用户」白名单（内部圈定，后续扩大开放用）
- **开放口径**：**仅内部使用**——知识检索、视频片段播放、Agent 知识引用均不对普通注册用户开放
- **架构定位**：按「课程 = 知识源」抽象，温成趋势理论为首个知识源；后续其他体系化课程可按同一管线接入
- **不涉及**：视频内容对外分发；通用网页/文档爬取入库（知识源一律由管理员主动登记）

### 1.3 术语表

| 术语 | 含义 |
|------|------|
| 知识源（课程） | 一个体系化课程的登记单元：讲师、体系名称、描述、章节目录树与素材集合；如「温成·趋势理论」 |
| 素材（集） | 课程下的一集视频/音频文件，存 COS，附时长、大小、转写状态 |
| 转写文稿 | 素材经云端 ASR 生成的时间戳文稿，按语义段落切分为分段，每段带起止时间码 |
| 章节目录树 | 课程的章 → 节（→ 知识点）层级结构，由 LLM 从文稿推断、人工修订定稿 |
| 知识点 | 最小知识单元的结构化卡片：标题、正文、类型（概念/定理/方法/纪律/案例）、术语定义、适用场景、关联知识点、定位（集数+句级起止时间区间）、原文摘录；是检索与引用的最小单元 |
| 索引构建 | 对已发布知识点做 embedding 向量化并写入 ES 混合索引的过程，由后台触发 |
| 混合检索 | BM25 关键词与 dense_vector 语义召回并行、RRF 融合排序 |
| 优化建议单 | Agent 自主技能优化的产物：对某技能的修改点列表（原文/建议文/diff）、理由、引用的知识点；人工审核后应用 |
| 关键帧定位 | 检索命中后可直接跳转播放的精确位置：集数 + 句级起止时间区间（由 ASR 句级时间戳支撑），定位精度目标 ±2 秒 |
| 防盗下载 | 代理播放隐藏源地址、短时效播放凭证、播放器禁下载交互、用户水印与异常拉取审计等组合手段，阻止视频文件被直接获取 |

## 2. 平台既有设施与衔接点（2026-09-13 实证）

| 既有设施 | 现状 | 本需求如何衔接 |
|----------|------|----------------|
| Elasticsearch 8.13 | 本地与生产均已部署；现有 `kb-documents` 索引仅承载研报关键词检索 | 新建独立 `kb-knowledge` 索引（dense_vector + BM25），不侵入研报索引；**不引入新向量库** |
| COS 对象存储 | 研报 PDF 已走 COS + `file_metadata` 登记 | 视频素材沿用同一存储与登记模式 |
| LLM 配置（`llm_config` + 后台页） | 仅 chat 模型概念 | 扩展「用途」维度（chat / embedding）；ASR 渠道在知识库设置内独立配置，密钥复用既有加密实践（Fernet，`app/utils/crypto.py`） |
| 采集任务体系 | TASK_SPECS internal 渠道、后台手动触发、`collector_log` 日志与健康监测 | 转写/抽取/索引构建等长任务声明为 internal 任务执行，天然获得进度日志与监控 |
| AI 交互范式 | 长任务禁止阻塞式 HTTP 端点 | 全部建库流水线任务化，后台只做触发与状态查询 |
| Skill 体系 | `skills/<id>/` 自包含资产（builtin，代码库文件）+ `skill` 表 custom 行（DB 存储，version 机制）+ 技能广场 | 自主优化的应用通道区分 builtin/custom（见 F-KB-07） |
| Agent 工具链 | `build_assistant_tools()` 按会话注册 | 新增知识检索工具，按用户权限门控注入 |
| 权限体系 | admin 角色 + 后台独立入口 | 知识库后台模块挂 admin；检索页与 Agent 工具按 admin/白名单门控 |

**能力缺口（全部为本需求新增）**：ASR 转写管线、embedding 向量化、知识源/素材/章节/知识点数据模型、索引构建任务、内部检索页、Agent 检索工具、技能优化建议闭环。

## 4. 总体设计（知识流水线）

```
多集视频 ──后台上传──▶ COS（素材登记，按集管理）
                          │ ① 整季转写任务（云端 ASR，逐集断点续跑）
                          ▼
                    时间戳文稿 ──语义分段──▶ 文稿分段
                          │ ② 章节目录推断 + 知识点抽取（LLM 结构化）
                          ▼
                    章节树 + 知识点草稿 ──人工审核/修订──▶ 发布
                          │ ③ 索引构建任务（embedding + ES 混合索引）
                          ▼
                    kb-knowledge 索引（dense_vector + BM25）
                          ├──▶ 内部知识检索页（搜知识点 / 浏览章节 / 关键帧定位回看，防盗播放）
                          └──▶ Agent 消费
                                 ├─ 运行时：search_knowledge_base 引用理论依据
                                 └─ 进化：对照知识库产出技能优化建议单 → 人工审核 → 应用升版
```

- ①②③均为后台触发的任务化执行（复用采集任务体系），HTTP 端点只负责触发与查询状态
- 知识点为两级消费单元：卡片（标题+正文）供检索命中与 Agent 引用；命中后附原文分段与集数/时间码供溯源回看
- 知识库是"活水"（可修订、可重建索引），技能是"固化产物"（版本化）；课程更新后可重放 ②③ 并触发技能再优化

## 5. 功能需求

### 5.1 F-KB-01 课程与素材管理（后台）

- **描述**：后台「知识库」模块首页。课程（知识源）CRUD：讲师、体系名称、描述、启用状态；课程下按集管理素材：上传视频/音频（大文件直传 COS，单集与整季大小上限可配）、批量上传多集（按文件名排序自动编号，可手动调整集号）、登记外部文稿导入（TXT/SRT，跳过 ASR）；素材列表展示每集时长、大小、转写状态、知识点数、索引状态
- **关键规则**：
  - 删除课程级联清理 COS 文件、文稿、章节、知识点与索引文档（软删除 + 异步清理，防误删不可恢复）
  - 素材按文件哈希去重；集号唯一（课程内）
  - 知识库设置：ASR 渠道参数（base_url / API Key / 模型 / 并发上限 / 参考单价）、金融热词表（背驰、中枢、三买等，转写时注入）、分段长度、embedding 模型选择（用途=embedding 的 LLM 配置条目）
- **权限**：全部操作限 admin 角色

### 5.2 F-KB-02 视频转写流水线（云端 ASR）

- **描述**：按集或整季触发转写：上传云端 ASR API → 拉取带时间戳文稿 → 清洗（去语气词、基础错字修正、段落归并）→ 生成分段文稿。每集独立任务，整季触发时逐集入队、并发上限受设置约束
- **关键规则**：
  - **成本前置确认**：整季触发前按「总时长 × 参考单价」预估费用，管理员确认后才执行；实际用量（音频时长/调用量）记录进任务 metadata，事后可对账
  - **断点续跑**：已完成分片落盘，任务中断重跑不重复计费转写
  - **句级时间戳**：转写结果保留句级时间码（语义分段由句聚合而成），句级时间戳随文稿入库——这是检索精准定位到关键播放位置（F-KB-05）的数据基础
  - **文稿可人工编辑**：ASR 是初稿，后台提供每集文稿编辑器作为质量最后防线
  - 转写渠道仅云端 API（一期不做本地 Whisper）；渠道不可用时任务失败原因写入日志，不静默重试烧钱
- **产出**：每集句级时间戳文稿与语义分段，状态机 `pending → transcribing → cleaning → done / failed`，进度（已转写时长/总时长）按集可见

### 5.3 F-KB-03 章节推断与知识点抽取、审核

- **描述**：文稿就绪后触发「知识抽取」任务（按集或整季）：
  - **章节目录推断**：LLM 跨集汇总推断课程大纲（章 → 节），生成目录树草稿
  - **知识点抽取**：LLM 按输出 Schema 逐段/跨段抽取知识卡片：标题、正文（保留讲师原意与表述习惯）、类型（概念/定理/方法/纪律/案例）、术语定义、适用场景、关联知识点、定位（集数+句级起止时间区间）、原文摘录
- **关键规则**：
  - 结构化输出 Schema **字段全 required、禁带默认值**（防止模型省略字段的项目既有教训）
  - 审核工作台（后台）：目录树逐节点确认/修订/拖拽调整；知识卡片逐条「通过 / 修订后通过 / 驳回」，支持人工新增、合并重复、维护关联关系与章节归属
  - 仅**已发布**知识点参与索引与检索；驳回不影响其他卡片
- **产出**：定稿章节树 + `published` 状态知识点

### 5.4 F-KB-04 索引构建与混合检索服务

- **描述**：
  - **索引构建任务**（后台按课程/按集触发，支持全量重建）：已发布知识点调 embedding 向量化，连同正文、术语、章节、定位写入 ES `kb-knowledge` 索引（dense_vector + BM25 双通道）
  - **检索服务**：query 双路召回 + RRF 融合；支持课程、章节、知识点类型过滤；返回知识卡片 + 命中原文分段 + 可直接跳转的句级时间区间定位（自动附前滚上下文，命中句前 3~5 秒起播）+ 得分
- **关键规则**：
  - embedding 模型/维度变更视为索引 breaking change：切换模型后强制全量重建，重建期间旧索引经别名继续可查，完成后无缝切换（避免新旧向量混排）
  - 新发布知识点自动进待索引队列，由构建任务增量拾取（最终一致，非实时）
  - 知识点删除/驳回同步删索引文档；性能目标检索 P95 < 500ms，top_k 可配（默认 8）
- **数据**：新表 `kb_source` / `kb_media` / `kb_transcript_segment` / `kb_knowledge_point`（幂等 SQL 迁移规范，同步 init-scripts）

### 5.5 F-KB-05 内部知识检索页与视频回看播放器（后台内）

- **描述**：后台「知识库」模块的检索 Tab（admin 可见；预留白名单授权后内部用户可访问）。搜索框 + 章节目录树导航 + 结果列表：知识卡片（标题、类型徽标、摘要、命中词高亮），展开显示原文摘录与**关键帧定位**（第 N 集 hh:mm:ss–hh:mm:ss）；支持知识点间关联跳转
- **精准定位回看**：点击命中结果或知识点定位，打开内置播放器并**自动 seek 到句级时间区间起点**（含前滚上下文），命中区间在进度条上高亮；支持该区间一键重播 / A-B 循环，便于反复揣摩讲解片段
- **播放器功能（常规能力齐备）**：
  - 播放/暂停、进度条拖拽与缓冲指示、音量与静音
  - 倍速播放（0.5x–2x，记忆用户偏好）、全屏、画中画
  - 键盘快捷键（空格播放暂停、←/→ 快退快进、↑/↓ 音量）
  - 断点续播（记忆每集上次播放位置）、播放器内上一集/下一集切换
  - **字幕联动**：转写文稿作为字幕轨，播放时当前句同步高亮；点击任意字幕句跳转到对应时间点（文稿即视频导航）
- **关键规则**：检索 API 走项目 camelCase wire 约定（shared/types 单一真相源），query 参数 snake_case 跟随后端签名；页面与播放按权限门控，视频流经服务端代理播放（见 F-KB-09），前端不接触 COS 直链
- **定位**：本页不做面向普通用户的分发入口；如未来开放，按白名单配置渐进扩大

### 5.6 F-KB-06 Agent 运行时知识引用

- **描述**：新增 `search_knowledge_base(query, chapter?, point_type?)` 工具，注册进 `build_assistant_tools()`，返回压缩知识卡片集（标题+正文+定位），控制 token 预算
- **关键规则**：
  - **权限门控**：仅 admin / 知识库授权用户的会话注入该工具；普通用户会话不注册（内部知识不外泄）
  - 分析类技能（复盘/异动/涨停等）的 SKILL.md allowed-tools 增补引用，提示词声明「涉及趋势与买卖点判断时先检索知识库取理论依据，结论注明引用知识点」——引用而非全文注入，渐进披露
  - 引用可溯源：回答中的知识点带集数/时间码，可回检索页核对
  - 降级：知识库不可用时工具返回明确错误文本，Agent 继续分析但声明未引用理论依据，不阻塞主流程
- **补充**：定时 AI 任务（复盘/异动等）如需理论加持，经服务层直调检索服务（不经工具层）

### 5.7 F-KB-07 Agent 自主技能优化（建议 → 审核 → 应用）

- **描述**：让 Agent 对照知识库审查并改进平台技能，**产出建议、人工审核、通过后应用**的闭环：
  - **触发**：后台选择「目标技能 × 知识源」手动触发优化任务（如「复盘技能 × 温成趋势理论」）；课程索引重建完成后提示可触发；**不做无人值守定时自动改写**
  - **执行**：优化 Agent 读取目标技能定义（SKILL.md / prompt 模板 / 输出 Schema）→ 检索知识库相关知识点 → 产出**优化建议单**：修改点列表（原文 / 建议文 / diff）、修改理由、引用知识点（含定位）、预期收益说明
  - **审核**：后台建议单队列，管理员逐项「通过 / 修订后应用 / 驳回」，可整体驳回附原因
  - **应用（按技能类型分通道）**：
    - **custom 技能**（DB 存储）：通过后直接写入新版本（version+1），即时生效
    - **builtin 技能**（`skills/<id>/` 代码库资产，部署不可变）：通过后导出修改后的完整文件文本 + 变更说明，由开发评审后落入代码库——运行时**不直接改写代码库文件**
- **关键规则**：
  - Agent 只产出建议，**任何修改不经审核不生效**；建议单全量留档可溯（谁触发、引用了哪些知识点、谁审核）
  - 优化产出中的方法论表述必须附知识来源定位，便于回溯视频原文
  - 同一技能未处理完的建议单存在时，禁止发起新一轮优化（防建议漂移）

### 5.8 F-KB-08 检索测试与运营统计（P2）

- **描述**：后台 playground——任意 query 查看双路召回与融合得分分解，用于调分段/top_k/权重；统计面板：知识点数、索引文档数、检索量、高频 query、零结果 query（指导补知识）

### 5.9 F-KB-09 视频防盗下载（与 F-KB-05 同期交付）

- **描述**：视频为内部课程资产，必须阻止被直接下载。多层防护组合：
  - **代理播放，隐藏源地址**：视频流一律经后端鉴权代理输出（支持 HTTP Range 分段请求以支撑拖拽/倍速），COS 地址与预签名信息永不暴露给前端
  - **短时效播放凭证**：每次播放向后端申请一次性播放凭证（绑定登录会话 + 权限校验，有效期 ≤30 分钟），过期自动失效需重新申请；凭证可限定到单集
  - **播放器交互禁下载**：无下载按钮、禁用右键/长按菜单、`controlsList=nodownload`、关闭浏览器原生下载入口（前端手段为提高门槛，安全性不依赖此层）
  - **异常拉取拦截**：非播放器特征请求（无 Range 的整文件抓取、高频连续分段拉取、无效凭证）直接拒绝并记录审计事件；连续异常触发账号级播放封禁告警
  - **用户水印溯源**：播放画面叠加当前用户身份水印（一期静态角标：用户名/ID + 时间；动态漂移水印后置），震慑录屏分发并支持溯源
- **边界声明**：技术目标是显著提高直接获取与批量盗取的成本，**不承诺防录屏/翻拍**；COS 桶保持私有读，原片不落在任何可公开枚举的路径

## 6. 非功能需求

| 项 | 要求 |
|----|------|
| 权限 | 后台管理与审核限 admin；检索页与 Agent 知识工具限 admin + 知识库授权白名单（默认空，按需圈定）；普通用户全链路不可见 |
| 长任务 | 转写/抽取/索引/优化建议全部任务化（采集任务体系承载），可触发/盯进度/重试；HTTP 端点不承载分钟级以上阻塞 |
| 时区 | 任务调度北京时间（Asia/Shanghai），时间戳 aware UTC；视频时间码为集内相对时间，与日期无关 |
| 性能 | 检索 P95 < 500ms；转写吞吐受并发上限约束，整季任务排队可预期（各集状态独立可见） |
| 成本 | ASR 与 embedding 调用前置预估、事后对账（用量入任务 metadata）；文稿未变不重转、知识点未变不重嵌 |
| 合规 | 视频与文稿仅限平台内部研究与教育使用，不提供原片下载与对外分发；引用标注讲师与课程名 |
| 防盗与溯源 | 视频不可被直接下载：代理播放隐藏源地址、短时效一次性凭证、播放器无下载入口、用户水印、异常拉取审计与封禁告警（见 F-KB-09）；录屏无法根除，以水印溯源震慑 |
| 可用性 | 知识库链路故障不影响既有业务页面与采集；ES 不可用时检索页友好报错、Agent 工具降级（见 F-KB-06） |

## 7. 功能边界

**包含**：课程与素材管理、云端 ASR 转写（句级时间戳）、章节推断与知识点抽取审核、索引构建与混合检索、内部检索页与回看播放器（关键帧定位/字幕联动/常规播放功能）、视频防盗下载（F-KB-09）、Agent 运行时知识引用（权限门控）、Agent 技能优化建议闭环、检索测试（P2）
**不包含**：面向普通用户开放（含助手工具）——如需开放另行立项；引入新向量库（复用 ES）；本地 Whisper 转写；多语言转写（一期仅中文）；视频自动剪辑成片；知识源自动爬取；技能修改不经审核直接生效；绝对防盗（录屏/翻拍无法根除，以水印溯源震慑）
